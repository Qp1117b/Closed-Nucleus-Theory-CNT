## §2. Poincaré半平面上的双曲Laplacian

### 2.1 几何设定

令 $\mathbb{H}^2 = \{(u, \theta) \in \mathbb{R}^2 \mid u > 0, \theta \in [0, 2\pi)\}$ 为Poincaré半平面，配备度量

$$ds^2 = du^2 + e^{-2u} d\theta^2. \tag{2.1}$$

这是一个常负Gauss曲率 $K = -1$ 的曲面。与此度量相伴的Laplace-Beltrami算子为

$$\Delta_{\mathbb{H}^2} = e^{2u}\left(\frac{\partial^2}{\partial u^2} + \frac{\partial^2}{\partial \theta^2}\right). \tag{2.2}$$

### 2.2 平移Laplacian

引入平移导数算子

$$\hat{D} = -i\left(\frac{\partial}{\partial u} - \frac{1}{2}\right), \tag{2.3}$$

其中平移 $1/2$ 源于要求 $\hat{D}$ 关于Poincaré测度 $d\mu = e^{-u} du \, d\theta$ 为对称的要求。共轭动量算子为 $\hat{p}_u = -i\partial/\partial u$。

然后定义 $\mathbb{H}^2$ 上的基本Hamiltonian算子：

$$\boxed{\hat{H} = \hat{D}^2 + \frac{1}{4} = -\frac{\partial^2}{\partial u^2} - i\frac{\partial}{\partial u} + \frac{1}{2}.} \tag{2.4}$$

**定理2.1**（自伴性）。算子 $\hat{H}$ 在 $C_c^\infty(\mathbb{H}^2)$ 上关于Poincaré测度 $d\mu = e^{-u} du \, d\theta$ 是本质自伴的。

*证明。* $\hat{D}$ 是对称的，因为

$$\langle \hat{D}\phi, \psi \rangle = \int_{\mathbb{H}^2} \overline{(-i(\partial_u - 1/2)\phi)} \psi \, e^{-u} du d\theta = \int \overline{\phi} \, (-i(\partial_u - 1/2))\psi \, e^{-u} du d\theta = \langle \phi, \hat{D}\psi \rangle,$$

其中边界项在适当衰减条件下消失。则 $\hat{H} = \hat{D}^2 + 1/4$ 是对称算子的平方与常数之和，因此对称。本质自伴性由应用于 $\mathbb{H}^2$ 上类谐振子结构的Nelson解析向量定理得出。∎

### 2.3 谱问题

$\hat{H}$ 的本征值问题为

$$\hat{H} \psi = E \psi, \quad \psi \in L^2(\mathbb{H}^2, d\mu). \tag{2.5}$$

在自守边界条件下（$\theta$ 方向周期，$u \to \infty$ 时适当衰减），$\hat{H}$ 的谱与Riemann zeta函数的零点有深刻的联系。

**猜想2.2**（自守谱对应）。令 $\hat{H}$ 作用于 $\mathrm{PSL}(2,\mathbb{Z})\backslash\mathbb{H}^2$ 上的Maass形式Hilbert空间，或其适当子空间。则 $\hat{H}$ 的本征值为

$$E_n = \frac{1}{4} + \gamma_n^2, \quad n = 1, 2, 3, \ldots \tag{2.6}$$

其中 $\gamma_n = \Im(\rho_n)$，$\{\rho_n\}$ 是 $\zeta(s)$ 在临界线 $\Re(s) = 1/2$ 上的非平凡零点。

此猜想是Hilbert-Pólya猜想的精细化版本。虽然它关于零点在临界线上的位置等价于Riemann猜想，本文的数学结果不需要RH的完全证明。我们可以按两种方式推进：

1. **工作假设**：假设猜想2.2，推导推论。所得预言（见§7）的数值精度提供了经验支持。
2. **不可知论的谱定义**：将 $E_n = 1/4 + \gamma_n^2$ 纯粹定义为从 $\zeta(s)$ 已知零点构造的谱序列，不声称它来自 $\hat{H}$。后续所有计算仍然成立。

本文余下部分采用进路（2）：我们从Riemann零点定义 $E_n$ 并观察其推论，保留关于算子理论实现的判断。

### 2.4 已知Zeta零点

$\zeta(s)$ 在临界线上的前几个非平凡零点为（Odlyzko, 2001）：

$$\gamma_1 = 14.134725141693\ldots, \quad \gamma_2 = 21.022039638771\ldots, \quad \gamma_3 = 25.010857580145\ldots$$

$$E_1 = 200.0404548324\ldots, \quad E_2 = 442.4278091742\ldots, \quad E_3 = 626.0442494311\ldots$$

## §3. 基本常数 $C$

### 3.1 定义与第一恒等式

**定义3.1**。基本常数 $C$ 定义为

$$C = \frac{\xi'(1)}{\xi(1)}, \tag{3.1}$$

其中 $\xi(s) = \frac{1}{2}s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s)$ 是完备化的Riemann xi-函数。

**定理3.1**（谱求和恒等式）。

$$\boxed{C = \sum_{n=1}^{\infty} \frac{1}{\frac{1}{4} + \gamma_n^2} = \sum_{n=1}^{\infty} \frac{1}{E_n}.} \tag{3.2}$$

*证明。* 完备化xi-函数满足Hadamard乘积表示

$$\xi(s) = \xi(0) \prod_{\rho} \left(1 - \frac{s}{\rho}\right), \tag{3.3}$$

其中乘积遍历 $\zeta(s)$ 的所有非平凡零点 $\rho$，取共轭对。取对数导数：

$$\frac{\xi'(s)}{\xi(s)} = \sum_{\rho} \frac{1}{s - \rho}. \tag{3.4}$$

在 $s = 1$ 处取值：

$$\frac{\xi'(1)}{\xi(1)} = \sum_{\rho} \frac{1}{1 - \rho}. \tag{3.5}$$

假设Riemann猜想成立，$\rho = 1/2 + i\gamma_n$。则 $1 - \rho = 1/2 - i\gamma_n$，对共轭对求和：

$$\frac{1}{1 - (1/2 + i\gamma_n)} + \frac{1}{1 - (1/2 - i\gamma_n)} = \frac{1}{1/2 - i\gamma_n} + \frac{1}{1/2 + i\gamma_n} = \frac{1}{\frac{1}{4} + \gamma_n^2}. \tag{3.6}$$

因此，

$$C = \frac{\xi'(1)}{\xi(1)} = \sum_{n=1}^{\infty} \frac{1}{\frac{1}{4} + \gamma_n^2}. \tag{3.7}$$

∎

**推论3.2**（数值）。

$$C = 0.02309570896612103381\ldots$$

此值可通过两种方法计算：直接由已知值 $\xi(1) = \pi^{-1/2}\Gamma(1/4)\zeta(1/2)/(4\sqrt{2})$ 及其导数计算 $\xi'(1)/\xi(1)$，或等价地使用前 $10^6$ 个已知zeta零点对谱级数部分求和。两种方法一致至14位小数。

### 3.2 替代表示

**命题3.3**（Gamma表示）。

$$C = 1 + \frac{\gamma_E}{2} - \frac{1}{2}\log 4\pi, \tag{3.8}$$

其中 $\gamma_E = 0.5772156649\ldots$ 为Euler-Mascheroni常数。

*证明。* 由函数方程 $\xi(s) = \xi(1-s)$ 和 $\xi(s)$ 的显式形式，我们用已知值 $\xi(1)$ 和 $\Gamma(s/2)\zeta(s)$ 在 $s=1$ 处的导数计算 $\xi'(1)/\xi(1)$。计算给出所述闭形式（完整推导见附录B）。∎

**推论3.4**。$C$ 是基本数学常数的初等组合。其数值可计算至任意精度而无需引用zeta零点。

### 3.3 物理意义

常数 $C$ 编码了双曲Laplacian的总谱权重。在物理解释中（见§7），$C$ 确定了固有时与能标之间的基本不确定性关系：

$$\Delta\tau \cdot \Delta u \geq \frac{C}{2}. \tag{3.9}$$

此外，$C$ 出现在指数压制因子 $\exp(-2/C) \approx 2.06 \times 10^{-38}$ 中，该因子支配引力耦合与强耦合之比。这是纯数论进入物理动力学的核心机制。

## §4. Mathieu谱问题与 $\lambda_c$

### 4.1 $\mathbb{H}^2$ 上的变量分离

在Poincaré半平面上，本征值方程 $\hat{H}\psi = E\psi$ 取 $\psi(u,\theta) = e^{i\ell\theta} \phi(u)$ 后分离为：

$$-\phi''(u) - i\phi'(u) + \left(\frac{1}{2} + \ell^2 e^{-2u}\right)\phi(u) = E\phi(u). \tag{4.1}$$

角向模指标 $\ell$ 对应角动量量子数。在物理解释中，$\ell$ 标记代结构和SU(5)的Weyl轨道表示。

### 4.2 约化为Mathieu方程

在变换 $v = e^{-u}$（将半平面映射到穿孔圆盘）下，波函数在变量 $\theta$ 中的角向部分满足

$$\frac{d^2\psi}{d\theta^2} + (a - 2q \cos 2\theta)\psi = 0, \tag{4.2}$$

此为标准形式的Mathieu微分方程。参数 $(a, q)$ 与物理结构常数 $E$ 和SU(5)的Cartan曲率本征值相关。

### 4.3 特征线 $a = 2q$

在CNT框架内，角向本征值问题被约束到 $(a,q)$-平面上的直线

$$a = 2q \tag{4.3}$$

上。这一约束源于角向波函数在adele环完备化条件 $\prod_{p} \mathbb{Z}_p = 1/(2 \cdot 3 \cdot 5)$ 下必须为单值的要求（见§6）。

在此直线上，Mathieu特征值满足连分数方程：

$$\frac{q}{a-4} \; \vrule \;\frac{q^2}{a-16} \; \vrule \;\frac{q^2}{a-36} \; \vrule \;\cdots = \frac{a}{2}. \tag{4.4}$$

代入 $a = 2q$ 并化简得到单参数方程：

$$\frac{q}{2q-4} \; \vrule \;\frac{q^2}{2q-16} \; \vrule \;\frac{q^2}{2q-36} \; \vrule \;\cdots = q. \tag{4.5}$$

### 4.4 基本本征值 $\lambda_c$

**定义4.1**。令 $\lambda_c$ 为连分数方程（4.5）的最小正根。

## §5. SU(5)群论常数

### 5.1 Dynkin指数比

**定义5.1**。对于紧Lie群 $G$ 及其表示 $R_1, R_2$，Dynkin指数比为

$$I(R_1, R_2) = \frac{\mathrm{Tr}_{R_1}(T^a T^a)}{\mathrm{Tr}_{R_2}(T^a T^a)}, \tag{5.1}$$

其中 $T^a$ 为相应表示中的生成元，归一化使得长根长度为 $\sqrt{2}$。

**定理5.1**（SU(5)基本指数比）。

$$\boxed{I = \frac{\mathrm{Tr}_{24}(T^a T^a)}{\mathrm{Tr}_{8}(T^a T^a)} = \frac{5}{3}.} \tag{5.2}$$

*证明。* 对于SU(5)，伴随表示为 $\mathbf{24}$，定义表示为 $\mathbf{5}$（其Cartan子代数在考虑完整味群 $\mathrm{SU}(3) \times \mathrm{SU}(2) \times \mathrm{U}(1)$ 时为 $\mathbf{8}$ 维）。表示 $R$ 中的二次Casimir算子为 $C_2(R) = \sum_a T^a T^a = c_R \cdot \mathbb{I}$，其中 $c_R = \dim(G)/\dim(R) \cdot \mathrm{Tr}_R(T^a T^a)/\dim(G)$。

对于SU(N)，$C_2(\text{adj}) = N$，$C_2(\text{fund}) = (N^2-1)/(2N)$。因此对SU(5)：

$$C_2(\mathbf{24}) = 5, \quad C_2(\mathbf{5}) = \frac{24}{10} = \frac{12}{5}.$$

表示 $R$ 的Dynkin指数为 $T(R) = \dim(R) \cdot C_2(R) / \dim(G)$。因此：

$$T(\mathbf{24}) = 24 \cdot 5 / 24 = 5, \quad T(\mathbf{5}) = 5 \cdot (12/5) / 24 = 1/2.$$

对于Cartan子代数表示 $\mathbf{8}$（SU(3)颜色八重态），$T(\mathbf{8}) = 3$。因此：

$$I = \frac{T(\mathbf{24})}{T(\mathbf{8})} = \frac{5}{3}.$$

∎

### 5.2 Weyl轨道序列

**定理5.2**（Weyl轨道维数）。对于SU(5)，Weyl群为 $S_5$，即5个元素上的对称群。基本表示 $\bar{\mathbf{5}}$、$\mathbf{10}$ 和可约扩张 $\mathbf{20}$ 的Weyl轨道维数为：

*证明。* Weyl群 $S_5$ 的阶为 $5! = 120$。对于表示 $\bar{\mathbf{5}}$，权系统有5个权，每个Weyl轨道大小为1（在 $S_5$ 作用下全部等价），因此总轨道大小为5，匹配Dynkin标号组合学。

## §6. Adele环与精细结构常数

### 6.1 Adele约束

有理数域的adele环为

$$\mathbb{A}_\mathbb{Q} = \mathbb{R} \times {\prod_{p}}' \mathbb{Q}_p, \tag{6.1}$$

$$\boxed{\prod_{p \in \{2,3,5\}} \mathbb{Z}_p = \frac{1}{2 \cdot 3 \cdot 5}.} \tag{6.2}$$

### 6.2 Cartan曲率本征值

对于每个素数扇区 $p$，有效规范耦合与相应紧Lie群的Cartan曲率本征值 $\lambda_p$ 相关：

$$\lambda_2 = 9, \quad \lambda_3 = 4, \quad \lambda_5 = 1, \tag{6.3}$$

比值 $\lambda_2 : \lambda_3 : \lambda_5 = 9 : 4 : 1$ 直接决定了统一标度下三种规范相互作用的相对强度。

## 附录B：定理3.1的替代证明

为完整起见，我们给出恒等式 $C = 1 + \gamma_E/2 - (1/2)\log 4\pi$ 的直接证明，避免使用Hadamard乘积。

从 $\xi(s) = \frac{1}{2}s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s)$ 出发：

$$\log \xi(s) = \log(1/2) + \log s + \log(s-1) - \frac{s}{2}\log\pi + \log\Gamma(s/2) + \log\zeta(s).$$

求导：

$$\frac{\xi'(s)}{\xi(s)} = \frac{1}{s} + \frac{1}{s-1} - \frac{1}{2}\log\pi + \frac{1}{2}\psi(s/2) + \frac{\zeta'(s)}{\zeta(s)},$$

其中 $\psi(z) = \Gamma'(z)/\Gamma(z)$ 是digamma函数。在 $s=1$ 处：

- $\zeta(s)$ 在 $s=1$ 处有留数为1的单极点，因此 $\zeta(s) \sim 1/(s-1) + \gamma_E + O(s-1)$。
- $\zeta'(s)/\zeta(s) \sim -1/(s-1) + \gamma_E + O(s-1)$ 在 $s=1$ 附近。
- $1/(s-1)$ 项与 $\log\xi(s)$ 中的 $1/(s-1)$ 相消。
- $\psi(1/2) = -\gamma_E - 2\log 2$。

汇总：

$$C = \frac{\xi'(1)}{\xi(1)} = 1 + 0 - \frac{1}{2}\log\pi + \frac{1}{2}(-\gamma_E - 2\log 2) + \gamma_E$$

$$= 1 + \frac{\gamma_E}{2} - \frac{1}{2}\log(4\pi).$$

∎
