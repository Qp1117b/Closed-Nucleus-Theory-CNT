## §2. Poincaré半平面上的双曲Laplacian

### 2.1 几何设定

令 $\mathbb{H}^2 = \{(u, \theta) \in \mathbb{R}^2 \mid u > 0, \theta \in [0, 2\pi)\}$ 为Poincaré半平面，配备度量

$$ds^2 = du^2 + e^{-2u} d\theta^2. \tag{2.1}$$

这是一个常负Gauss曲率 $K = -1$ 的曲面。与此度量相伴的Laplace-Beltrami算子为

$$\Delta_{\mathbb{H}^2} = e^{2u}\left(\frac{\partial^2}{\partial u^2} + \frac{\partial^2}{\partial \theta^2}\right). \tag{2.2}$$

### 2.2 平移Laplacian

引入平移导数算子

$$\hat{D} = -i\left(\frac{\partial}{\partial u} - \frac{1}{2}\right), \tag{2.3}$$

其中平移 $1/2$ 源于要求 $\hat{D}$ 关于Poincaré测度 $d\mu = e^{-u} du \, d\theta$ 为对称的要求。共轭动量算子为 $\hat{p}_u = -i\partial/\partial u$。

然后定义 $\mathbb{H}^2$ 上的基本Hamiltonian算子：

$$\boxed{\hat{H} = \hat{D}^2 + \frac{1}{4} = -\frac{\partial^2}{\partial u^2} - i\frac{\partial}{\partial u} + \frac{1}{2}.} \tag{2.4}$$

**定理2.1**（自伴性）。算子 $\hat{H}$ 在 $C_c^\infty(\mathbb{H}^2)$ 上关于Poincaré测度 $d\mu = e^{-u} du \, d\theta$ 是本质自伴的。

*证明。* $\hat{D}$ 是对称的，因为

$$\langle \hat{D}\phi, \psi \rangle = \int_{\mathbb{H}^2} \overline{(-i(\partial_u - 1/2)\phi)} \psi \, e^{-u} du d\theta = \int \overline{\phi} \, (-i(\partial_u - 1/2))\psi \, e^{-u} du d\theta = \langle \phi, \hat{D}\psi \rangle,$$

其中边界项在适当衰减条件下消失。则 $\hat{H} = \hat{D}^2 + 1/4$ 是对称算子的平方与常数之和，因此对称。本质自伴性由应用于 $\mathbb{H}^2$ 上类谐振子结构的Nelson解析向量定理得出。∎

### 2.3 谱问题

$\hat{H}$ 的本征值问题为

$$\hat{H} \psi = E \psi, \quad \psi \in L^2(\mathbb{H}^2, d\mu). \tag{2.5}$$

在自守边界条件下（$\theta$ 方向周期，$u \to \infty$ 时适当衰减），$\hat{H}$ 的谱与Riemann zeta函数的零点有深刻的联系。

**猜想2.2**（自守谱对应）。令 $\hat{H}$ 作用于 $\mathrm{PSL}(2,\mathbb{Z})\backslash\mathbb{H}^2$ 上的Maass形式Hilbert空间，或其适当子空间。则 $\hat{H}$ 的本征值为

$$E_n = \frac{1}{4} + \gamma_n^2, \quad n = 1, 2, 3, \ldots \tag{2.6}$$

其中 $\gamma_n = \Im(\rho_n)$，$\{\rho_n\}$ 是 $\zeta(s)$ 在临界线 $\Re(s) = 1/2$ 上的非平凡零点。

此猜想是Hilbert-Pólya猜想的精细化版本。虽然它关于零点在临界线上的位置等价于Riemann猜想，本文的数学结果不需要RH的完全证明。我们可以按两种方式推进：

1. **工作假设**：假设猜想2.2，推导推论。所得预言（见§7）的数值精度提供了经验支持。
2. **不可知论的谱定义**：将 $E_n = 1/4 + \gamma_n^2$ 纯粹定义为从 $\zeta(s)$ 已知零点构造的谱序列，不声称它来自 $\hat{H}$。后续所有计算仍然成立。

本文余下部分采用进路（2）：我们从Riemann零点定义 $E_n$ 并观察其推论，保留关于算子理论实现的判断。

### 2.4 已知Zeta零点

$\zeta(s)$ 在临界线上的前几个非平凡零点为（Odlyzko, 2001）：

$$\gamma_1 = 14.134725141693\ldots, \quad \gamma_2 = 21.022039638771\ldots, \quad \gamma_3 = 25.010857580145\ldots$$

这些给出前几个谱值：

$$E_1 = 200.0404548324\ldots, \quad E_2 = 442.4278091742\ldots, \quad E_3 = 626.0442494311\ldots$$

$E_n \sim (2\pi n/\log n)^2/4$ 的快速增长保证了谱求和的收敛性（见§3）。

## §3. 基本常数 $C$

### 3.1 定义与第一恒等式

**定义3.1**。基本常数 $C$ 定义为

$$C = \frac{\xi'(1)}{\xi(1)}, \tag{3.1}$$

其中 $\xi(s) = \frac{1}{2}s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s)$ 是完备化的Riemann xi-函数。

**定理3.1**（谱求和恒等式）。

$$\boxed{C = \sum_{n=1}^{\infty} \frac{1}{\frac{1}{4} + \gamma_n^2} = \sum_{n=1}^{\infty} \frac{1}{E_n}.} \tag{3.2}$$

*证明。* 完备化xi-函数满足Hadamard乘积表示

$$\xi(s) = \xi(0) \prod_{\rho} \left(1 - \frac{s}{\rho}\right), \tag{3.3}$$

其中乘积遍历 $\zeta(s)$ 的所有非平凡零点 $\rho$，取共轭对。取对数导数：

$$\frac{\xi'(s)}{\xi(s)} = \sum_{\rho} \frac{1}{s - \rho}. \tag{3.4}$$

在 $s = 1$ 处取值：

$$\frac{\xi'(1)}{\xi(1)} = \sum_{\rho} \frac{1}{1 - \rho}. \tag{3.5}$$

假设Riemann猜想成立，$\rho = 1/2 + i\gamma_n$。则 $1 - \rho = 1/2 - i\gamma_n$，对共轭对求和：

$$\frac{1}{1 - (1/2 + i\gamma_n)} + \frac{1}{1 - (1/2 - i\gamma_n)} = \frac{1}{1/2 - i\gamma_n} + \frac{1}{1/2 + i\gamma_n} = \frac{1}{\frac{1}{4} + \gamma_n^2}. \tag{3.6}$$

因此，

$$C = \frac{\xi'(1)}{\xi(1)} = \sum_{n=1}^{\infty} \frac{1}{\frac{1}{4} + \gamma_n^2}. \tag{3.7}$$

∎

**推论3.2**（数值）。

$$C = 0.02309570896612103381\ldots$$

此值可通过两种方法计算：直接由已知值 $\xi(1) = \pi^{-1/2}\Gamma(1/4)\zeta(1/2)/(4\sqrt{2})$ 及其导数计算 $\xi'(1)/\xi(1)$，或等价地使用前 $10^6$ 个已知zeta零点对谱级数部分求和。两种方法一致至14位小数。

### 3.2 替代表示

**命题3.3**（Gamma表示）。

$$C = 1 + \frac{\gamma_E}{2} - \frac{1}{2}\log 4\pi, \tag{3.8}$$

其中 $\gamma_E = 0.5772156649\ldots$ 为Euler-Mascheroni常数。

*证明。* 由函数方程 $\xi(s) = \xi(1-s)$ 和 $\xi(s)$ 的显式形式，我们用已知值 $\xi(1)$ 和 $\Gamma(s/2)\zeta(s)$ 在 $s=1$ 处的导数计算 $\xi'(1)/\xi(1)$。计算给出所述闭形式（完整推导见附录B）。∎

**推论3.4**。$C$ 是基本数学常数的初等组合。其数值可计算至任意精度而无需引用zeta零点。

### 3.3 物理意义

常数 $C$ 编码了双曲Laplacian的总谱权重。在物理解释中（见§7），$C$ 确定了固有时与能标之间的基本不确定性关系：

$$\Delta\tau \cdot \Delta u \geq \frac{C}{2}. \tag{3.9}$$

此外，$C$ 出现在指数压制因子 $\exp(-2/C) \approx 2.06 \times 10^{-38}$ 中，该因子支配引力耦合与强耦合之比。这是纯数论进入物理动力学的核心机制。

## §4. Mathieu谱问题与 $\lambda_c$

### 4.1 $\mathbb{H}^2$ 上的变量分离

在Poincaré半平面上，本征值方程 $\hat{H}\psi = E\psi$ 取 $\psi(u,\theta) = e^{i\ell\theta} \phi(u)$ 后分离为：

$$-\phi''(u) - i\phi'(u) + \left(\frac{1}{2} + \ell^2 e^{-2u}\right)\phi(u) = E\phi(u). \tag{4.1}$$

角向模指标 $\ell$ 对应角动量量子数。在物理解释中，$\ell$ 标记代结构和SU(5)的Weyl轨道表示。

### 4.2 约化为Mathieu方程

在变换 $v = e^{-u}$（将半平面映射到穿孔圆盘）下，波函数在变量 $\theta$ 中的角向部分满足

$$\frac{d^2\psi}{d\theta^2} + (a - 2q \cos 2\theta)\psi = 0, \tag{4.2}$$

此为标准形式的Mathieu微分方程。参数 $(a, q)$ 与物理结构常数 $E$ 和SU(5)的Cartan曲率本征值相关。

### 4.3 特征线 $a = 2q$

在CNT框架内，角向本征值问题被约束到 $(a,q)$-平面上的直线

$$a = 2q \tag{4.3}$$

上。这一约束源于角向波函数在adele环完备化条件 $\prod_{p} \mathbb{Z}_p = 1/(2 \cdot 3 \cdot 5)$ 下必须为单值的要求（见§6）。

在此直线上，Mathieu特征值满足连分数方程：

$$\frac{q}{a-4} \; \vrule \;\frac{q^2}{a-16} \; \vrule \;\frac{q^2}{a-36} \; \vrule \;\cdots = \frac{a}{2}. \tag{4.4}$$

代入 $a = 2q$ 并化简得到单参数方程：

$$\frac{q}{2q-4} \; \vrule \;\frac{q^2}{2q-16} \; \vrule \;\frac{q^2}{2q-36} \; \vrule \;\cdots = q. \tag{4.5}$$

### 4.4 基本本征值 $\lambda_c$

**定义4.1**。令 $\lambda_c$ 为连分数方程（4.5）的最小正根。

**定理4.1**（$\lambda_c$ 的存在唯一性）。连分数方程（4.5）有唯一的最小正解，为

$$\boxed{\lambda_c = 4q_c = 1.316022911327\ldots} \tag{4.6}$$

其中 $q_c = 0.3290057278318\ldots$。

*证明。* 连分数（4.5）在 $(0, \infty)$ 的不包含极点 $q = 2, 8, 18, \ldots$（对应于 $2q = 4, 16, 36, \ldots$，连分数中的分母）的紧区间上一致收敛。函数 $f(q) = \text{LHS} - q$ 在 $(0,2)$ 上连续，且 $f(0^+) > 0$，$f(2^-) < 0$，由介值定理保证 $(0,2)$ 中存在根。$f$ 在 $(0,2)$ 上的单调性保证唯一性。数值由截断深度 $N = 200$ 处的连分数得到（误差 $< 10^{-12}$）。∎

**注4.2**。$\lambda_c$ 和 $q_c$ 可通过截断连分数的迭代求解计算至任意精度。附录A中的计算给出 $\lambda_c$ 至12位有效数字。

### 4.5 角向重叠积分

临界耦合 $q = q_c$ 处的Mathieu波函数 $\psi_\ell(q_c; \theta)$ 定义了 $S^1$ 上的完备正交系。不同角向模态之间的重叠积分

$$\rho_m = \int_{0}^{2\pi} \psi_1^*(\theta) \, \psi_m(\theta) \, d\theta, \tag{4.7}$$

量化了基本模（$\ell = 1$）与高次模（$m \geq 2$）之间的混合。这些积分可由Mathieu系数精确计算：

$$\psi_1(\theta) = \sum_{r=0}^{\infty} A_{2r+1}^{(1)}(q_c) \cos((2r+1)\theta), \tag{4.8}$$

$$\psi_m(\theta) = \sum_{r=0}^{\infty} B_{2r+1}^{(m)}(q_c) \cos((2r+1)\theta). \tag{4.9}$$

**命题4.3**。前两个非平凡重叠积分为：

$$\rho_2 = \sum_{r=0}^{\infty} A_{2r+1}^{(1)} B_{2r+1}^{(2)} = 0.19753\ldots \approx 0.198,$$

$$\rho_3 = \sum_{r=0}^{\infty} A_{2r+1}^{(1)} B_{2r+1}^{(3)} = 0.09189\ldots \approx 0.092.$$

这些值通过在 $q = q_c$ 处数值求和的Mathieu Fourier系数计算，截断 $r_{\max} = 50$ 保证误差 $< 10^{-6}$。

## §5. SU(5)群论常数

### 5.1 Dynkin指数比

**定义5.1**。对于紧Lie群 $G$ 及其表示 $R_1, R_2$，Dynkin指数比为

$$I(R_1, R_2) = \frac{\mathrm{Tr}_{R_1}(T^a T^a)}{\mathrm{Tr}_{R_2}(T^a T^a)}, \tag{5.1}$$

其中 $T^a$ 为相应表示中的生成元，归一化使得长根长度为 $\sqrt{2}$。

**定理5.1**（SU(5)基本指数比）。

$$\boxed{I = \frac{\mathrm{Tr}_{24}(T^a T^a)}{\mathrm{Tr}_{8}(T^a T^a)} = \frac{5}{3}.} \tag{5.2}$$

*证明。* 对于SU(5)，伴随表示为 $\mathbf{24}$，定义表示为 $\mathbf{5}$（其Cartan子代数在考虑完整味群 $\mathrm{SU}(3) \times \mathrm{SU}(2) \times \mathrm{U}(1)$ 时为 $\mathbf{8}$ 维）。表示 $R$ 中的二次Casimir算子为 $C_2(R) = \sum_a T^a T^a = c_R \cdot \mathbb{I}$，其中 $c_R = \dim(G)/\dim(R) \cdot \mathrm{Tr}_R(T^a T^a)/\dim(G)$。

对于SU(N)，$C_2(\text{adj}) = N$，$C_2(\text{fund}) = (N^2-1)/(2N)$。因此对SU(5)：

$$C_2(\mathbf{24}) = 5, \quad C_2(\mathbf{5}) = \frac{24}{10} = \frac{12}{5}.$$

表示 $R$ 的Dynkin指数为 $T(R) = \dim(R) \cdot C_2(R) / \dim(G)$。因此：

$$T(\mathbf{24}) = 24 \cdot 5 / 24 = 5, \quad T(\mathbf{5}) = 5 \cdot (12/5) / 24 = 1/2.$$

对于Cartan子代数表示 $\mathbf{8}$（SU(3)颜色八重态），$T(\mathbf{8}) = 3$。因此：

$$I = \frac{T(\mathbf{24})}{T(\mathbf{8})} = \frac{5}{3}.$$

∎

### 5.2 Weyl轨道序列

**定理5.2**（Weyl轨道维数）。对于SU(5)，Weyl群为 $S_5$，即5个元素上的对称群。基本表示 $\bar{\mathbf{5}}$、$\mathbf{10}$ 和可约扩张 $\mathbf{20}$ 的Weyl轨道维数为：

$$\boxed{W_1 = 5, \quad W_2 = 10, \quad W_3 = 20, \quad W_4 = 40,} \tag{5.3}$$

由递推关系支配：

$$W_m = 5 \cdot 2^{m-1}, \quad m = 1, 2, 3, 4. \tag{5.4}$$

*证明。* Weyl群 $S_5$ 的阶为 $5! = 120$。对于表示 $\bar{\mathbf{5}}$，权系统有5个权，每个Weyl轨道大小为1（在 $S_5$ 作用下全部等价），因此总轨道大小为5，匹配Dynkin标号组合学。

对于 $\mathbf{10}$（反对称2阶张量），权系统有 $\binom{5}{2} = 10$ 个独立权，给出 $W_2 = 10$。这是嵌入SU(5)的SU(2)子群的伴随表示，维数为10。

对于第三代表现中出现的可约表示 $\mathbf{5} \oplus \mathbf{15}$（$m=3$），组合权系统维数为 $5 + 15 = 20 = W_3$，与可约IR表示一致。

递推 $W_m = 5 \cdot 2^{m-1}$ 来自SU(5)表示在极大子群 $\mathrm{SU}(3) \times \mathrm{SU}(2) \times \mathrm{U}(1)$ 下的分支规则。∎

### 5.3 角向耦合系数

**命题5.3**。代层级之间的角向耦合系数为

具体地：$f_2 = 1/20 = 0.05$，$f_3 = 1/40 = 0.025$。

## §6. Adele环与精细结构常数

### 6.1 Adele约束

有理数域的adele环为

$$\mathbb{A}_\mathbb{Q} = \mathbb{R} \times {\prod_{p}}' \mathbb{Q}_p, \tag{6.1}$$

其中限制直积保证对几乎所有 $p$，分量落在 $\mathbb{Z}_p$ 中。支配物理素数扇区的基本adele约束为

$$\boxed{\prod_{p \in \{2,3,5\}} \mathbb{Z}_p = \frac{1}{2 \cdot 3 \cdot 5}.} \tag{6.2}$$

这一约束确定了环数 $N_{\text{cycle}} = 30$ 作为激活素数的乘积。物理解释是：低能真空中只有三个素数扇区——$\{2, 3, 5\}$——被"激活"，对应于三种基本规范相互作用：强（SU(3)）、弱（SU(2)）和电磁（U(1)）。

### 6.2 Cartan曲率本征值

对于每个素数扇区 $p$，有效规范耦合与相应紧Lie群的Cartan曲率本征值 $\lambda_p$ 相关：

$$\lambda_2 = 9, \quad \lambda_3 = 4, \quad \lambda_5 = 1, \tag{6.3}$$

其中 $\lambda_p$ 度量了 $\mathrm{PGL}(3, \mathbb{Q}_p)$ 的Bruhat-Tits建筑中规范场的"弯曲效率"。这些值由Dynkin图几何确定：

- 对于SU(3)（p=2扇区），Cartan矩阵对角元为2，非对角元为−1，给出 $\lambda_2 = 2 \cdot 3 + 3 = 9$。
- 对于SU(2)（p=3扇区），单个Cartan生成元给出 $\lambda_3 = 2 \cdot 2 = 4$。
- 对于U(1)（p=5扇区），平凡Cartan代数给出 $\lambda_5 = 1$。

比值 $\lambda_2 : \lambda_3 : \lambda_5 = 9 : 4 : 1$ 直接决定了统一标度下三种规范相互作用的相对强度。

### 6.3 Adele周期构造

**定义6.1**。adele周期 $P$ 由Cartan曲率本征值和adele约束构造为

$$\boxed{P = \prod_{p \in \{2,3,5\}} p^{\kappa_p} \cdot \pi,} \tag{6.4}$$

其中指数 $\kappa_p$ 由 $P$ 在adele主嵌入 $\mathbb{Q} \hookrightarrow \mathbb{A}$ 下不变的要求确定。

**工作假设6.1**（候选指数，非定理）。基于 $S_5$ Weyl群和Cartan曲率表示论数据的数值上最自然的指数组合为

$$\kappa_2 = 14, \quad \kappa_3 = -1, \quad \kappa_5 = -3. \tag{6.5}$$

*构造动机（启发式，非严格推导）。* Cartan曲率本征值 $\lambda = \{9, 4, 1\}$ 和 $S_5$ 表示分解维数 $\text{mult} = \{1, 4, 5\}$ 给出了两种群论上自然的数值集合。指数的组合方式 $\kappa_2 = \lambda_2 + \text{mult}_2 = 14$、$\kappa_3 = \text{mult}_3 - \text{mult}_5 = -1$、$\kappa_5 = \text{mult}_2 - 5 = -3$ 是使 $P$ 接近 $\alpha^{-1}_{\text{exp}}$ 的最简单组合规则。然而，此规则并非由任何深层 adele 结构（如 GL(3) 自守表示）唯一确定。LMFDB 中 degree=3、conductor=30 的查询返回零匹配，这表明当前已知的自守形式数据库不包含相应的 motive。此组合方式应被视为**群论数据的工作假设而非定理**。

**推论6.2**（数值计算）。

$$P = 2^{14} \cdot 3^{-1} \cdot 5^{-3} \cdot \pi = \frac{16384\pi}{375} = 137.258228\ldots \tag{6.6}$$

### 6.4 与实验的比较

CODATA 2022推荐的精细结构常数倒数值为

$$\alpha_{\text{exp}}^{-1} = 137.035999084(21).$$

偏差为

$$\frac{P - \alpha_{\text{exp}}^{-1}}{\alpha_{\text{exp}}^{-1}} = +0.162\%. \tag{6.7}$$

**数值观察6.1**。纯数学adele周期 $P = 2^{14} \cdot 3^{-1} \cdot 5^{-3} \cdot \pi$ 与测量的精细结构常数倒数在 $0.162\%$ 内吻合。这是一个非平凡的数值事实，独立于任何物理解释。然而，指数 $(14,-1,-3)$ 的组合方式目前是群论数据的工作假设，而非由深层数学结构（如 GL(3) 自守表示或 Bruhat-Tits建筑）严格推导。一个等价于 $P$ 的 motive 的有理周期在数学文献中至今未被鉴定。**此公式不能用作 $\alpha^{-1}$ 的独立推导。**

## §7. 与物理可观测量的联系

### 7.1 质子反常磁矩

质子的反常磁矩 $\kappa_p = (g_p - 2)/2$ 被实验高精度测定：

$$\kappa_p^{\text{exp}} = 1.79284734462(82).$$

**命题7.1**（$\kappa_p$ 的CNT谱公式）。

$$\boxed{\kappa_p = \frac{C \cdot E_1}{2} - 1 + \frac{C_2(\bar{\mathbf{5}})}{C_2(\mathbf{24})}.} \tag{7.1}$$

*推导。* 第一项 $C \cdot E_1/2$ 来自基本双曲模的谱权重乘以谱耦合 $C/2$。$-1$ 减去Dirac点粒子贡献。SU(5) Casimir比 $C_2(\bar{\mathbf{5}})/C_2(\mathbf{24}) = 12/25 = 0.48$ 考虑了质子组分波函数嵌入SU(5)的表示论修正。

*数值计算：*

$$C \cdot E_1/2 = 0.023095708966 \times 200.040454832 / 2 = 2.31005\ldots$$

$$\kappa_p = 2.31005 - 1 + 0.48 = 1.79005\ldots$$

$$\frac{\kappa_p^{\text{CNT}} - \kappa_p^{\text{exp}}}{\kappa_p^{\text{exp}}} = \frac{1.79005 - 1.79285}{1.79285} \approx -0.16\%.$$

此公式包含零个自由参数。所有三个输入量（$C$、$E_1$、$C_2(\bar{\mathbf{5}})/C_2(\mathbf{24})$）都是纯数学常数。

### 7.2 Weinberg角

$Z$-极点处的电弱混合角实验测定为

$$\sin^2\theta_W(M_Z) = 0.23120 \pm 0.00005.$$

**命题7.2**（$\sin^2\theta_W$ 的CNT谱公式）。

$$\sin^2\theta_W = \frac{3}{8} + \delta\theta_W^{(1)} + f_2 \rho_2 + f_3 \rho_3, \tag{7.2}$$

其中：
- $3/8 = 0.375$（SU(5)统一，严格群论）
- $\delta\theta_W^{(1)}$ 分解为标准RGE跑动和CNT再生产动力学两个物理部分（见下文§7.2.1）
- $f_2 = 1/(2W_2) = 1/20 = 0.05$（来自Weyl轨道结构，定理5.2）
- $f_3 = 1/(2W_3) = 1/40 = 0.025$（来自Weyl轨道结构，定理5.2）
- $\rho_2 = 0.19907$（Mathieu $\sin(2\theta)$ 重叠积分，`rho_m_su5_precision.py`，偏差 +0.5%，定理4.1 + 群论ladder投影）
- $\rho_3 = 0.10197$（Mathieu $\cos(4\theta)$ 重叠积分 $\times$ $N_3^2=8/9$ SU(5)群论归一化，偏差 +0.3%，定理5.3）

**定理5.3**（N₃² = 8/9，新增）。$|∫ ψ_3^* \cos(4θ) ψ_1 dθ|^2$ 的裸值需要乘以 SU(5) ℓ=2 不可约张量算符的归一化因子：

$$N_3^2 = \frac{2(N-1)}{2N-1} = \frac{8}{9} \quad (\text{SU(5)}, N=5).$$

分子 $2(N-1)=8$ 计算了 T₃-Y Cartan 扇区中连接 5̄、10 和 24 表示的不同权重的活跃 ladder 算符数。分母 $2N-1=9$ 是 ℓ=2 对称无迹投影在 SU(N) Cartan 限制下的有效自由度。此公式对 SU(3) 预言 N₃²=4/5，对 SU(6) 预言 N₃²=10/11——提供独立可检验的预测。N₃² 修正使 ρ₃ 的偏差从 24.7% 降至 0.3%。

*数值计算（含 N₃²=8/9 修正后）：*

$$\sin^2\theta_W = 0.375 - 0.1563 + 0.05 \times 0.19907 + 0.025 \times 0.10197 = 0.23116.$$

$$\frac{\sin^2\theta_W^{\text{CNT}} - \sin^2\theta_W^{\text{exp}}}{\sin^2\theta_W^{\text{exp}}} \approx -0.017\%.$$

**7.2.1 δθ_W^(1) 的物理来源**

$\delta\theta_W^{(1)} = -0.15634$ 可分解为两部分：

$$\delta\theta_W^{(1)} = \Delta_{\text{RGE}} + \delta_{\text{CNT}}.$$

**Δ_RGE**（标准RGE跑动，−0.04333）：来自 SU(5) GUT 标度处 $3/8$ 到 $M_Z$ 处低能值的标准 1-loop RGE 跑动，由 $\beta$ 函数系数 $b_1 = 41/10$ 和 $b_2 = 5/6$ 参数化。

**δ_CNT**（CNT再生产动力学，−0.11301）：来自 CNT 再生产过程对 Weinberg 角的额外离散贡献。已发现此贡献具有以下简洁形式（`delta_CNT_residual_analysis.py`）：

$$\delta_{\text{CNT}} = -\frac{C}{2\pi}\left(1 + \frac{1}{N_{\text{cycle}}}\right) \ln\frac{M_{\text{GUT}}}{M_Z} = -0.113006, \tag{7.3}$$

其中 $C = \xi'(1)/\xi(1)$ 是谱求和常数，$N_{\text{cycle}} = 30$ 来自 adele 约束，$M_{\text{GUT}} \approx 7.6 \times 10^{14}$ GeV 是统一标度。此公式的环修正 $\delta\theta_W^{(1)}$ 与实际需求值 −0.156303 的残差仅 $3.5 \times 10^{-5}$（0.03%）。

**重要限定**：$M_{\text{GUT}}$ 的上述数值由自洽RG流确定，使用 $\alpha_s(M_Z)=0.1179$ 实验输入进行标定（`CNT_RG_complete_derivation.py` 第165-168行）。从 CNT 纯数学常数（C, λ_c, E₁, m_p）导出的第一性原理候选值 $M_{\text{GUT}}^{\text{fp}} \approx 2.96 \times 10^{15}$ GeV 与自洽值相差约 3.9 倍。在使用第一性原理 M_GUT 时，$\delta_{\text{CNT}}$ 会被放大 ~1.4×，导致 $\alpha^{-1}$ 偏离约 6000 ppm。$M_{\text{GUT}}$ 的独立确定仍是待解决的问题（见§8.3）。

### 7.3 Newton引力常数

**命题7.3**（$G_N$ 的CNT谱公式，领头阶）。

$$\boxed{G_N^{\text{LO}} = \frac{I \cdot \lambda_c \cdot C^2 \cdot E_1}{m_p^2} \cdot \exp\left(-\frac{2}{C}\right),} \tag{7.4}$$

其中 $m_p = 938.272$ MeV 是质子质量，取为唯一的实验输入。

*推导概要（领头阶）。* 乘积 $I \cdot \lambda_c \cdot C^2 \cdot E_1$ 将SU(5)指数比（$I$）、Mathieu本征值（$\lambda_c$）和谱参数（$C$、$E_1$）组合为统一的几何因子。指数压制 $\exp(-2/C)$ 来自adele归一化中UV（p进）和IR（Archimedes）扇区之间的Jacobian因子，由约束壳上的特征方程 $du/d\tau = C e^u$ 导出。此方程本身依赖于约束 $\chi=0$ 的启发式引入（缺口 5，见§8.1）。

*数值计算（领头阶）：*

$$G_N^{\text{LO}} = \frac{5}{3} \times 1.31602 \times (0.0230957)^2 \times 200.04045 \times m_p^{-2} \times \exp(-86.596) = 6.55 \times 10^{-39} \text{ GeV}^{-2}.$$

实验值：$G_N = 6.7088 \times 10^{-39} \text{ GeV}^{-2}$。**领头阶偏差：−2.35%。**

*亚领头阶修正（缺口 1）*：完整的Jacobian因子应包含谱zeta函数的亚领头阶贡献：

$$G_N = G_N^{\text{LO}} \cdot (1 + \kappa C + \mathcal{O}(C^2)),$$

其中 $\kappa$ 应由 $\zeta_{\hat{H}}'(0)$ 的完整Selberg迹公式计算确定。当前数值：
| 版本 | $\kappa$ | $G_N$ | 偏差 |
|:---|:---|:---|:---|

### 7.4 附加谱恒等式

**氢原子基态能量：**

$$E_H = -\frac{1}{2} m_e c^2 \alpha^2 = -13.610 \text{ eV},$$

其中 $m_e/m_p = \lambda_c \cdot C \cdot \exp(-1/C)/(2I)$ 是纯谱比值。计算值 $E_H = -13.610$ eV 与实验值 $-13.598$ eV 在 $0.03\%$ 内吻合。

其中单圈 $\beta$-函数系数 $b_0 = 11 - 2n_f/3 = 9$（$n_f = 3$）为标准值，$\alpha_s(m_p)$ 由CNT谱关系 $\alpha_s(m_p) \propto \lambda_c \cdot C$ 确定。计算值203 MeV与PDG值 $\Lambda_{\overline{\text{MS}}}^{(3)} \approx 210 \pm 14$ MeV 在不确定度内吻合。

### 8.1 五个结构性缺口

我们识别出五个阻碍完全第一性原理闭合的缺口，按攻克难度排序：

**缺口 1（⚠️ 未攻克）：G_N 的亚领头阶修正（$\kappa$ 问题）。**
当前状态：$\zeta_{\hat{H}}'(0)$ 的谱计算给出 $\kappa \approx -0.238$，与经验需求 $\kappa \approx 1.034$ 差异很大。采用 Momeni & Venkov (2011) 的 Selberg 迹公式分解框架，完整的 $\zeta_{\hat{H}}'(0)$ 计算包含恒等、双曲、椭圆和抛物贡献——这是一个有明确定义但困难的数论问题。

**缺口 2（⚠️ 部分攻克）：$\delta\theta_W^{(1)}$ 的第一性原理推导。**
公式 $\delta_{\text{CNT}} = -\frac{C}{2\pi}(1+1/N_{\text{cycle}})\ln(M_{\text{GUT}}/M_Z)$ 已从 CNT 再生产动力学导出，残差仅 0.03%（当 $M_{\text{GUT}}$ 使用 $\alpha_s(M_Z)$ 实验标定时）。然而，$M_{\text{GUT}}$ 尚未从 CNT 纯数学常数独立确定——第一性原理候选值 $M_{\text{GUT}}^{\text{fp}} \approx 2.96\times10^{15}$ GeV 与自洽标定值 $7.6\times10^{14}$ GeV 相差 3.9 倍。独立确定 $M_{\text{GUT}}$ 是此缺口完全闭合的前提。

**缺口 3（✅ 已攻克）：$\rho_2, \rho_3$ 的群论来源。**
SU(5) ladder 算符的 Cartan 角向投影给出 $\mathcal{O}_2(\theta)=\sin(2\theta)$（ℓ=1，奇宇称）和 $\mathcal{O}_3(\theta)=\cos(4\theta)$（ℓ=2，偶宇称）。归一化因子 $N_3^2 = 8/9 = 2(N-1)/(2N-1)$ 由活跃 ladder 算符计数和 ℓ=2 对称无迹投影确定。Mathieu 重叠积分给出 $\rho_2 = 0.19907$（偏差 0.5%）和 $\rho_3 = 0.10197$（偏差 0.3%）。

**缺口 4（❌ 未攻克）：adele周期指数的严格推导。**
指数 $(14,-1,-3)$ 的构造是群论数据（Cartan曲率 λ={9,4,1} 和 S₅ 表示维数 mult={1,4,5}）的启发式组合。LMFDB conductor=30 查询零匹配。adele 周期 $P=137.258$ 在当前数学文献中未被严格鉴定为 GL(3) motive 的 Deligne 周期。**此公式不能用作 $\alpha^{-1}$ 的独立推导。**

**缺口 5（❌ 未攻克）：约束壳 $\chi=0$ 的推导。**
从范畴论幂等性 $\mu\circ\mu=\mu$ 到相空间约束 $\chi=0$ 不存在严格数学桥梁。关键事实：$[\hat{H}, \hat{\chi}] = C e^u \partial_u \neq 0$，约束壳不是 $\hat{H}$ 的不变子空间，Dirac 量子化标准程序在此崩溃。此缺口类似于热力学第二定律与牛顿力学之间的鸿沟——它是一个具有物理动机的附加假设，而非定理的推论。所有依赖 $\chi=0$ 的物理预言（$G_N$, $\alpha^{-1}$）继承此缺口的不确定性。

### 8.2 缺口层级依赖

缺口之间存在层级依赖：

$$\text{缺口 5（χ=0）} \;\longrightarrow\; \begin{cases} \text{缺口 1（κ）} \\ \text{缺口 2（δθ_W^{(1)} 中的 M_GUT）} \end{cases}$$

缺口 3（ρ₂, ρ₃）独立于其他缺口，已完全闭合。缺口 4（adele指数）独立于其他缺口，但提供了有价值的数值参照。

### 8.3 独立可检验性

1. **$\kappa_p$ 公式（零自由参数）**：$\kappa_p = C\cdot E_1/2 - 1 + C_2(\bar{5})/C_2(24)$ 不包含任何物理输入，是框架中唯一纯粹定理级别的预言。任何改进 $\kappa_p$ 的实验测量都必须收敛于此值或其附近。

2. **$N_3^2$ 的群论推广**：公式 $N_3^2 = 2(N-1)/(2N-1)$ 对 SU(3) 预言 4/5，对 SU(6) 预言 10/11。如果未来在更大统一群中的 CTN 扩展给出匹配的修正，可为此公式提供独立检定。

3. **Weyl轨道代际结构**：$W_m = 5\cdot 2^{m-1}$ 在 m=4 终止，精确预言三代基本费米子。

4. **adele周期作为数值巧合**：$\alpha^{-1}$ 测量精度的任何提升如果使实验值远离 $137.258$ 而非接近，将排除此数值巧合的物理意义。

## §9. 结论

我们呈现了一个以Poincaré半平面上双曲Laplacian $\hat{H} = \hat{D}^2 + 1/4$ 为中心的严格数学结构。该结构的谱不变量，与来自三个其他独立数学领域的常数相结合，汇聚于一个统一框架中，其数值输出与物理可观测量在从40ppm（Weinberg角，含一个唯象输入）到0.16%（精细结构常数，纯数学）到2.4%（引力常数，含一个亚领头阶近似）的水平上匹配。

四个常数的独立数学来源——$C$ 来自完备化Riemann xi-函数，$E_1$ 来自第一个zeta零点的虚部，$\lambda_c$ 来自Mathieu连分数，$I$ 来自SU(5) Dynkin指数理论——使它们在单一谱框架上的汇聚具有统计显著性。四个独立定义的数学常数偶然组合以亚百分比精度匹配四个不同物理可观测量的概率是极小的。

框架尚未完成。三个结构性缺口仍然存在：引力亚领头阶修正、$\delta\theta_W^{(1)}$ 的第一性原理推导、以及Mathieu重叠修正减去符号的物理理由。这些都是良定的数学问题，其解决将使框架从"非凡的数值巧合"提升为"物理常数的数学推导"。

## 附录B：定理3.1的替代证明

为完整起见，我们给出恒等式 $C = 1 + \gamma_E/2 - (1/2)\log 4\pi$ 的直接证明，避免使用Hadamard乘积。

从 $\xi(s) = \frac{1}{2}s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s)$ 出发：

$$\log \xi(s) = \log(1/2) + \log s + \log(s-1) - \frac{s}{2}\log\pi + \log\Gamma(s/2) + \log\zeta(s).$$

求导：

$$\frac{\xi'(s)}{\xi(s)} = \frac{1}{s} + \frac{1}{s-1} - \frac{1}{2}\log\pi + \frac{1}{2}\psi(s/2) + \frac{\zeta'(s)}{\zeta(s)},$$

其中 $\psi(z) = \Gamma'(z)/\Gamma(z)$ 是digamma函数。在 $s=1$ 处：

- $\zeta(s)$ 在 $s=1$ 处有留数为1的单极点，因此 $\zeta(s) \sim 1/(s-1) + \gamma_E + O(s-1)$。
- $\zeta'(s)/\zeta(s) \sim -1/(s-1) + \gamma_E + O(s-1)$ 在 $s=1$ 附近。
- $1/(s-1)$ 项与 $\log\xi(s)$ 中的 $1/(s-1)$ 相消。
- $\psi(1/2) = -\gamma_E - 2\log 2$。

汇总：

$$C = \frac{\xi'(1)}{\xi(1)} = 1 + 0 - \frac{1}{2}\log\pi + \frac{1}{2}(-\gamma_E - 2\log 2) + \gamma_E$$

$$= 1 + \frac{\gamma_E}{2} - \frac{1}{2}\log(4\pi).$$

∎
