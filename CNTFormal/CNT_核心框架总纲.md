## 四、关键命题

### 4.1 固有时离散论

> **固有时是再生产计数，不是终极背景。坐标时是统计涌现。**

- 不存在先于再生产的固有时
- 人类可识别时间远未触及普朗克时间
- 固有时离散，但存在本身连续（历史唯物主义连续性）

### 4.2 坍缩即再生产

> **不存在独立的"坍缩"过程。波函数坍缩 = 再生产循环的离散跳跃。**

- 无"连续演化"与"突然坍缩"的二分
- 单次循环结果就是确定的（某个具体状态）
- "波函数"是再生产循环关系的数学描述，非物理实在

### 4.3 黎曼路径积分 = 循环论连续极限

> **黎曼路径积分是CNT再生产路径积分的连续极限。循环论是黎曼路径积分的离散本体论。**

```
离散极限（CNT）：  ∑_{p进轨迹} e^{iS_p/ℏ_p}
        ↓ 连续极限
连续极限（QFT）：  ∫ e^{iS/ℏ} 𝒟[x(τ)]
```

### 4.4 概率性的本体论来源

> **单次循环的随机性来自张力不可完全中介性，非认识论缺陷。**

- 非经典随机（隐藏变量无知）
- 非标准量子随机（波函数坍缩）
- **CNT特有：本体论上不可消除的结构性随机**

### 4.5 传播子 = 单次再生产的内在展开结构【最新修正】

> **传播子不是再生产循环之间的外部中介，而是单次再生产循环本身的内在展开机制。**

```
单次再生产 = 一次"本体展开事件"

    有限本体（中子/质子）在时刻n的状态
        │
        ▼  传播子结构（内在展开机制）
        │
        ├── 虚光子路径（概率幅 ∝ 1/q²）
        ├── 虚W/Z路径（概率幅 ∝ 1/(q²-M²)）
        ├── 虚胶子路径（概率幅 ∝ 1/q²，色因子限制）
        └── ... 所有高阶虚历史
        │
        ▼  路径积分相干叠加 + 相位相消
        │
    有限本体在时刻n+1的状态
```

## 五、规范力的三重来源

| 规范力 | 传播子特征 | 再生产模式 | CNT对应 |
|--------|-----------|-----------|---------|
| **U(1)电磁** | 无质量、长程、矢量 | 最开放的再生产耦合 | 再生产与"外部"的耦合 |
| **SU(2)弱** | 有质量、短程、手性 | 手性翻转的再生产模式 | 再生产层级的突破 |
| **SU(3)强** | 无质量但色禁闭、渐近自由 | 最紧密的再生产束缚 | 闭合核内部的再生产 |

**三重性来源**：物理机制是**三种不同的概率动力学收敛模式**，不是几何投影。但在循环论相空间中，三条 RG 流仍然是母轨迹 $\vec{\Gamma}_k = (g_1^{(k)}, g_2^{(k)}, g_3^{(k)})$ 在三个坐标轴上的投影 $g_i(\tau) = \pi_i(\vec{\Gamma}_\tau)$——投影是**数学描述**，不是物理机制。就像地球轨道是椭圆——这是正确的数学描述，但物理机制是引力，不是"椭圆性"。

```
旧理解:  母轨迹（给定几何）→ 投影 → 三个 RG 流
正确理解: 三个传播子收敛模式 → 共同构成母轨迹 → 投影（数学描述）
```
