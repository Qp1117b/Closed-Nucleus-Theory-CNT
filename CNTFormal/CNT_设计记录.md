## 1. 符号约定

| 符号 | 含义 | 使用规范 |
|------|------|---------|
| $\hat{\mu}$ | 再生产算符（上游算符） | 仅用于上游/抽象语境。$\hat{\mu}^2 = \hat{\mu}$ 是再生产幂等性定义。不作为具体物理算符恒等于任何下游表达 |
| $\hat{\mu}_{\downarrow\text{dc}}$ | 下游退相干算符 | 退相干通道中的 $\hat{\mu}$ 表现。$\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$ |
| $\hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}$ | 因果自洽子空间正交投影（中性） | 不承诺存在论方向。黑洞蒸发、夸克禁闭均属此类。本身不是 $\hat{\mu}$ 的表现 |
| $\hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$ | 被再生产幂等性筛选后的投影 | 与 $\hat{\mu}_{\downarrow\text{dc}}$ 等同。$\mu^2=\mu$ 赋值使本征值 1 = 存在维持 |
| $\hat{H} = \hat{D}^2 + 1/4$ | 双曲Laplacian | Poincaré半平面上的谱动力学主体 |
| $\hat{\mathcal{G}} = -iCe^u\partial_u$ | RG流生成元 | 全局幺正约束筛选出的唯一动力学 |
| $C = \xi'(1)/\xi(1)$ | 第一谱不变量 | 数论定理 |
| $C' = \xi''(1)/\xi(1) - C^2$ | 第二谱不变量 | $C'<0$ 编码再生产箭头不可逆性 |

**关键区分规则**：
- 凡涉及 $\hat{\mu}$ 与 $\hat{\mathcal{P}}$ 的恒等式，必须使用 $\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$
- 单独使用 $\hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}$ 时必须明确其为"中性因果守门人"
- $\hat{\mu}$ 单独出现（无 = 等式）允许用于上游/桥接/逻辑缺口语境

## 3. 公理基础

| 层级 | 内容 | 状态 |
|------|------|------|
| L0 (物质先在) | 存在不可还原 | 公理预设 |
| L1 (再生产) | $\mu \circ \mu = \mu$ | 逻辑推论 |
| L2 (p进结构) | $\mathbb{Z}_p = \varprojlim \mathbb{Z}/p^n\mathbb{Z}$ | 再生产离散性的数学实现 |
| L3 (壳层几何 → 度规涌出) | $\hat{H} = \hat{D}^2 + 1/4$, $ds^2 = du^2 + e^{-2u}d\theta^2$ | ✅ 从 Ĝ 严格涌出（见 CNT_第一性严格化推导汇编 §7） |

| 恒等式 | 来源 | 严格性 |
|--------|------|--------|

| $\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$ | 退相干通道中的下游表现（被再生产筛选后的自耦退相干投影） | ⚠️ 形式化（因果结构推论） |
| $\hat{\mu}_{\downarrow\text{dc},1} = 0$ | 投影算符微扰论 | ✅ 定理 |
| $G_N = I \cdot \lambda_c \cdot C^2 \cdot E_1 \cdot \exp(-2/C) / m_p^2$ | 各因子独立推导 | ⚠️ 数值验证（−2.3%） |
