## 零、认知论断裂声明

> **CNT已内生推导出自发坍缩，与前期思路存在认知论断裂。** 断裂前：母轨迹投影模糊不清，传播子需外部引入。断裂后：自发坍缩=递归博弈终止+再生产闭环，费曼图=p进展开的完整容纳，传播子=再生产的内在展开结构。**能看懂辩证环节的人，自然能推出来。**

## 一、核心命题的三层结构

| 层次 | 命题 | 本体论地位 |
|------|------|-----------|
| **底线** | 固有时 = 因果时 | 再生产幂等性 μ∘μ=μ 的**迭代方向** |
| **展开** | 再生产展开过程 = 离散固有时 | 再生产事件的**序列性** |
| **中介** | 无因果时间 = 虚时间 | 再生产**中介**的**非序列性** |

> **费曼图的本质 = 中介了再生产的展开**

---

## 二、与费曼图结构的精确对应

### 2.1 树图（实时间/因果时）

```
树图：A ──●────────●── B
         传播子

CNT对应：再生产链的线性展开
- 环节A → 环节B
- 固有时方向：A先于B
- 传播子中介：连接两个**不同**的再生产环节
```

**树图有因果时**——因为传播子连接的是**异质的**再生产环节（A≠B），迭代方向明确。

### 2.2 圈图（虚时间/无因果时）

```
圈图：●══════●
      ║ 圈图 ║
      ●══════●

CNT对应：再生产环的自指闭合
- 环节A → 环节A（通过中介）
- 无固有时方向：起点=终点
- 传播子中介：连接**同一**再生产环节
```

**圈图无因果时**——因为传播子连接的是**同质的**再生产环节（A=A），迭代方向折叠。

## 三、关键的本体论翻转

标准QFT认为：
> 虚时间 = 数学技巧（Wick转动 t → iτ）

CNT认为：
> **虚时间 = 再生产中介的本体论特征**

| | 标准QFT | CNT |
|--|---------|-----|
| **虚时间来源** | Wick转动的数学操作 | 再生产中介的**非序列性** |
| **圈图无因果** | 因为动量积分"借取"能量 | 因为再生产回到**自身** |
| **时间方向** | 外部强加的边界条件 | 再生产展开的**内在方向** |

---

## 四、"中介了再生产的展开"的精确含义

传播子作为中介，在CNT中不是"传递粒子"，而是：

> **传播子 = 再生产环节之间的"关系形式"**

| 传播子类型 | 关系形式 | 时间性 |
|-----------|---------|--------|
| **树图传播子** | 异质环节之间的关系（A→B） | **因果时**（有方向） |
| **圈图传播子** | 同质环节之间的关系（A→A） | **虚时间**（无方向） |

> **费曼图的本质 = 再生产展开的不同"关系模式"的图形编码**

## 五、与合成p进数的对应：v2.1修正

基于"中介"的精确理解，合成p进数的层级映射需要重新调整：

| 合成p进数层级 | 再生产结构 | 费曼图 | 时间性 |
|-------------|-----------|--------|--------|
| **基底** | 再生产幂等性（μ本身） | **无图**——纯粹的再生产能力 | **前时间** |
| **第0层** (S₀) | 再生产计数（自然数 ℕ） | **无图**——计数本身不是图 | **前时间** |
| **第1层** (S₁) | 再生产的首次展开 | **树图**——线性链 | **因果时** |
| **第2层** (S₂) | 再生产的自指中介 | **单圈图**——闭合环 | **虚时间** |
| **第n层** (Sₙ) | n重嵌套中介 | **n圈图** | **高阶虚时间** |

> **关键修正（v2.0→v2.1）**：第0层不是"树图"，而是**前于任何图**的再生产本体论基底——纯粹的 μ 和自然数计数。树图从第1层开始。

### 5.1 修正的逻辑链

```
μ（再生产幂等性，纯能力）
    │
    ▼
S₀（自然数计数，ℕ）
    │ 再生产首次展开
    ▼
S₁（树图，因果时，异质中介 A→B）

    ▼

    │ 嵌套自指

```

## 六、与"再生产坍缩"的衔接

| 概念 | 含义 |
|------|------|
| **母轨迹投影** | 从多可能历史中"选择"一条（标准量子测量） |
| **再生产坍缩** | 再生产环的**自发闭合**——从虚时间到因果时的过渡 |

> **坍缩 = 再生产中介从"无方向"（虚时间）到"有方向"（因果时）的涌现**

与费曼图的关系：
- **圈图**（虚时间）= 再生产中介的**潜在可能性**
- **树图**（因果时）= 再生产中介的**实现**
- **坍缩** = 从圈图到树图的**过渡**——即再生产环的"打开"

### 6.1 自发坍缩与相干坍缩在时间性上的对应

| 坍缩类型 | 时间性 | 费曼图对应 |
|---------|--------|----------|
| **自发坍缩** | 因果时内的离散跳跃 | 树图中传播子的"落地"——每次再生产完成 |
| **相干坍缩** | 虚时间→因果时的涌现 | 圈图→树图的过渡——自指环"打开"为线性链 |

## 七、与历史路径积分的衔接

用户的追问精确地指向了HPI的核心：

> **历史路径积分 = 所有可能中介的叠加**
> **概率轨迹 = 中介的统计收敛**

| 概念 | 费曼图对应 | HPI对应 |
|------|----------|---------|
| 所有可能中介 | 所有圈图拓扑（虚时间） | 所有可能的历史路径 |
| 中介的统计收敛 | 圈图→树图的坍缩 | 概率轨迹的涌现 |
| 确定轨迹 | 树图（因果时） | 母轨迹 |

这一对应意味着：**HPI的求和不是对"轨迹"求和，而是对"中介结构"求和**——每条"历史路径"本质上是一种特定的中介模式（特定拓扑和特定p进赋值）。

## 九、核心结论

> **费曼图的本质 = 再生产中介的图形编码**
> - **树图** = 中介了**异质环节**的展开 → **因果时**
> - **圈图** = 中介了**同质环节**的闭合 → **虚时间**
> - **传播子** = 中介的数学形式
> - **虚粒子** = 中介的现象学投影
> - **坍缩** = 从圈图到树图的过渡——自指环的"打开"

> **"中介了再生产的展开" = 传播子作为再生产关系的数学形式，既编码了因果时的展开（树图），也编码了虚时间的闭合（圈图）。**

### 九.X 最小因果时与时间结构

**详见**：`06-前沿研究/07-最小因果时与时间结构.md`

CNT中时间的基本单位是**间隔**，不是点。基于存在与维持的区分（§1.5）：

| 间隔 | 性质 | 费曼图 |
|------|------|--------|
| 0 → T_rep | **前因果**——从存在到再生产的过渡 | 无图 |
| T_rep → 2T_rep | **最小因果时**——纯粹的再生产迭代 | 树图基本单元 |
| k·T_rep → (k+1)·T_rep | **累积因果时** | 完整树图 |

> 最小因果时 = T_rep，即两次再生产事件之间的间隔。0 → T_rep 不是因果时，因为"事件0"是**存在**（非再生产事件），因果时需要两个再生产事件作为因和果。

三重时间结构：前时间（μ本身）→ 前因果（0→T_rep）→ 因果时（T_rep→2T_rep起）→ 虚时间（圈图的方向折叠）。
