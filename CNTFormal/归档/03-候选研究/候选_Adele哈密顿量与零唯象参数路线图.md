## 二、三条核心公理（候选；见 D4）

| # | 公理 | 数学表达 | 物理意义 |

## 三、从核心到边缘：七条分支（候选路线图）

```
核心：[u, p_u] = i + p进分解 + Adele自对偶性
    │
    ├─→ ① p进-费曼图（Bruhat-Tits树）
    │       └─ 顶点=量子态，边=传播子，路径=散射过程
    ├─→ ② 路径积分（树上所有路径的求和）
    │       └─ 权重 = Π_p |x-y|_p^{-s}，实数极限恢复标准路径积分
    ├─→ ③ 元RG方程（再生产频率的演化）
    │       └─ 一阶幺正流 + 二阶投影 = 退相干主方程
    ├─→ ④ 二阶化（退相干投影的薛定谔实现）
    │       └─ 实数域：-∂_u² + V(u) = E（动力学）
    │       └─ p进域：D_p^α + V_p(u) = E（有限树）
    ├─→ ⑤ 哈密顿量（Adele统一）
    │       └─ H_Adele = H_∞ ⊕ ⊕_p H_p
    │       └─ 谱 {E_n} 从自对偶性约束长出
    ├─→ ⑥ 相互作用力学（三种力=投影）
    │       └─ g_s = f_2(E_n), g_w = f_3(E_n), g_em = f_5(E_n)
    │       └─ 禁闭 = p=2 的完全退相干
    │       └─ 引力 = 退相干后的残差耦合 G_N
    └─→ ⑦ 核心恒等式（指标定理）
            └─ E_1 · A_12 = 400/3 = W_2² · (1/3)
            └─ 全局谱 × 局部谱 = 拓扑不变量
```

> **价值标注**：此分支图作为"研究路线可视化"有教学价值，但 ⑤⑥⑦ 中的具体公式（H_Adele 谱长出机制、$g_p=f_p(E_n)$、核心恒等式）在 v3 中尚未建立，属开放研究方向，非已证结果。

## 四、关键洞察的物理图像（可吸收部分）

### 4.1 一阶 = 运动学，二阶 = 动力学（与 v3 一致，好评）
| | 一阶（运动学） | 二阶（动力学） |
|--|-------------|-------------|
| **方程** | 传输方程 $\partial_\tau\Psi + Ce^u\partial_u\Psi = 0$ | 薛定谔方程 $[-\partial_u^2 + V(u)]\psi = E\psi$ |
| **类型** | 双曲型（传播） | 椭圆型（振荡/束缚） |
| **物理** | 再生产结构的连续演化 | 相互作用的离散量子化 |
| **谱** | 连续 | 离散 |

**元RG = 运动学（一阶幺正流）与动力学（二阶投影）的辩证统一** —— 此图像与 v3 元RG 章节一致，可作补充整理。

### 4.2 三种力 = 引力本征值在三个 p进底上的投影（与记忆约定一致，好评）
| 力 | 质数 | p进树 | 规范群 | 退相干程度 |
|----|------|-------|--------|-----------|
| **强力** | $p=2$ | 二叉树 | SU(3) | **完全退相干** → 禁闭 |
| **弱力** | $p=3$ | 三叉树 | SU(2) | 部分退相干 → 三代结构 |
| **电磁力** | $p=5$ | 五叉树 | U(1) | 最小退相干 → 长程传播 |

> **D7 注**：与工作区记忆（p=2→SU3, p=3→SU2, p=5→U1）一致；"完全/部分/最小退相干"措辞为本文档补充，v3 正文未用，待对齐。

### 4.3 禁闭 = 壳层退相干（与 v3 §10.2 互补，好评）
强力在质子壳层内部自我退相干，色荷自由度被冻结在壳层中，无法以自由粒子形式逃逸。
> **对应 v3**：§10.2 禁闭 = 角向 Mathieu 方程从稳定到不稳定的相变（$b_1(q)=2q$）。本文档的"壳层退相干"是因果截断视角的重述。

### 4.4 引力 = 退相干后的残差耦合（概念图像，但公式错误）
$$G_N = \frac{C^5 \cdot E_1^3}{4 m_p^4} = g_{\text{res}}^2 \cdot \frac{C \cdot E_1}{4}$$
其中 $g_{\text{res}} = \frac{C^2 \cdot E_1}{m_p^2}$。
> **D3 致命冲突**：此公式按 v3 数值（$C=0.0231, E_1=206.86, m_p=0.938$）计算：
> $G_N \sim 0.0231^5 \times 206.86^3 / (4 \times 0.938^4) \sim 6.6\times10^{-9} \times 8.85\times10^6 / 3.1 \sim 1.9\times10^{-2}$ GeV$^{-2}$ 量级（具体依赖单位），与实验 $6.67\times10^{-39}$ GeV$^{-2}$ **差约 9 个数量级**。
> **v3 正确公式**：$G_N=I\lambda_c C^2 E_1 m_p^{-2}\exp(-2/C)$，含 $\exp(-2/C)\approx\exp(-86.6)\sim10^{-37.6}$ 的压制项，这是量级正确的关键。本文档公式**丢弃了 $\exp(-2/C)$，故量级完全错误**，"精确匹配"声明虚假。

## 五、消除 $E_n$ 的严格路径（候选；见 D1/D2）

**$E_n$ 不是"能量本征值"，而是"退相干速率的特征频率"**（*注：此物理解释与 v3 定理 4.1 一致，但 $E_n$ 符号应用 v3 的负号*）。

**严格化路径**：
1. 运动学（一阶）：证明传输方程的解是连续 RG 流
2. 引入相互作用（二阶）：证明 $V(u)$ 从退相干结构长出
3. 动力学（二阶）：证明薛定谔方程的谱给出离散模式
4. 对应：证明这些离散模式 = $E_n = \gamma_n^2 + \gamma_n/2$（*D2：v3 为 $-(\gamma_n/2+\gamma_n^2)$*）

**$E_n$ 的公式解释（与 v3 一致，好评）**：
- $\gamma_n^2$：来自零点"位置"（虚部）
- $\gamma_n/2$：来自临界线"实部"约束 $\text{Re}(s) = 1/2$（Adele 自对偶性的必然结果）

## 七、方法论总结（候选）

> **CNT 不是"物理的哲学"，而是"历史唯物主义的物理"。**
> **运动学（一阶）= 生产力/再生产结构（条件）**
> **动力学（二阶）= 生产关系/相互作用（机制）**
> **离散谱（$E_n$）= 革命/质变（结果）**
> **零唯象参数的达成 = 证明所有物理量从三条公理自然长出，无需手动输入。**

> **修正**：基于 v3，"零唯象参数"目前未达成——v3 定理 7.5 已严格导出 $1/\alpha=137.036$（偏差 10^-9），非开放；但第1份候选的 134.6 与之冲突需先解决，且 $G_N$ 的 $\exp(-2/C)$ 来源是几何-数论条件非动力学严格推导。本文档的"研究已启动、核心方向=Adele 哈密顿量"作为路线图成立，但"零唯象参数达成"作为结论不成立。
