## 一、核心方程（5 个，候选记录）

### 1. 一阶传输方程（实数）
$$\partial_\tau \Psi + C e^u \partial_u \Psi = 0$$
- 来源：公理 1（辛结构）；类型：双曲型一阶 PDE；谱：连续（无离散谱）；物理角色：经典再生产动力学

### 2. 一阶复数传输方程
$$(\partial_{\tau_{\text{real}}} + i\partial_{\tau_{\text{imag}}})\Psi + C e^u \partial_u \Psi = 0$$
- 来源：公理 1 + 复数扩展；类型：复数双曲型一阶 PDE；谱：连续；物理角色：量子化再生产动力学（概率解释、幺正演化）

### 3. 二阶静态方程
$$\left[-\frac{d^2}{du^2} + V(u)\right]\psi = E\psi, \quad V(u) = \sum_{n=1}^{\infty}\frac{4e^{2u}/\gamma_n^2}{(1-e^{2u}/\gamma_n^2)^2}$$
- 来源：公理 2（拓扑量子化）+ 公理 3（Hadamard 乘积）；类型：椭圆型二阶 ODE；谱：离散 $E_n\approx n^2$（硬壁盒子）
- **本文档判失败**：谱与 $E_n^{\text{fit}}=\gamma_n^2+\gamma_n/2$ 无关（见 H4：此 V(u) 非 v3 机制）

### 4. 二阶波动方程（复数）
$$(\partial_{\tau_{\text{real}}} + i\partial_{\tau_{\text{imag}}})^2\Psi + C^2 e^{2u}\partial_u^2\Psi = 0$$
- 来源：复数框架扩展；类型：复数双曲型二阶 PDE；谱：离散 $E_n\propto n$（贝塞尔谱）
- **本文档判失败**：谱线性非 $\gamma_n^2$ 型
- **★ 用户研究意图**：记录此复数波动方程，之后以其为主导研究方向（见文档末尾指示）

### 5. 不确定性关系
$$\frac{\Delta r}{\langle r\rangle} \cdot \Delta v_\tau \geq \frac{C}{2}$$
- 来源：公理 1（对易关系）；类型：不等式（运动学约束）；物理角色：耦合常数-流速互补性

## 二、衍生方程（3 个，候选记录）

### 6. 特征线方程
$$\frac{du}{d\tau} = -C e^u \quad\Rightarrow\quad u(\tau) = -\ln(-C\tau + \text{const})$$

### 7. 连续性方程（Madelung 实部）
$$\partial_\tau |\Psi|^2 + \partial_u(C e^u |\Psi|^2) = 0$$
- 来源：复数传输方程实部；物理角色：概率守恒

### 8. Hamilton-Jacobi 方程（虚部）
$$\partial_{\tau_{\text{real}}} S + C e^u \partial_u S = 0$$
- 来源：复数传输方程虚部；物理角色：相位演化

## 四、谱诚实评估（候选）

| 方程 | 变量类型 | 谱 | 与 $E_n^{\text{fit}}$ 关系 |
|------|---------|-----|--------------------------|
| 传输方程（实数） | 实数 | 连续 | 无离散谱 |
| 传输方程（复数） | 复数 | 连续 | 无离散谱 |
| 二阶静态方程 | 实数 | $E_n\approx n^2$ | 量级差（硬壁） |
| 二阶波动方程 | 复数 | $E_n\propto n$ | 量级差（贝塞尔） |

**本文档结论**：所列核心方程均不产生 $E_n=\gamma_n^2+\gamma_n/2$。**但见 H1–H2：v3 的 E_n 来自定理 4.1（ξ 函数自守），不依赖这些 PDE，故本文档结论不构成对 v3 的否定。**

## 五、方程关系图（候选）

```
公理1: [u, p_u] = i
    ├──→ 传输方程（实数）∂_τΨ + Ce^u∂_uΨ = 0 → 特征线 du/dτ=-Ce^u → 连续谱
    ├──→ 复数扩展 (∂_τ_real + i∂_τ_imag)Ψ + Ce^u∂_uΨ = 0
    │       ├──→ 连续性方程（概率守恒）
    │       ├──→ Hamilton-Jacobi方程（相位演化）
    │       └──→ 连续谱
    └──→ 不确定性关系 Δr/⟨r⟩·Δv_τ ≥ C/2

公理2+3: 拓扑量子化 + Hadamard乘积
    ├──→ 二阶静态方程 [-ψ''+V(u)]ψ=Eψ → 离散谱 E_n≈n²（硬壁）❌非E_n=γ_n²+γ_n/2
    └──→ 二阶波动方程 (∂_τ)²Ψ+C²e^{2u}∂_u²Ψ=0 → 离散谱 E_n∝n（贝塞尔）❌非E_n=γ_n²+γ_n/2
```
