# 11-代码实现

本目录用于 CNT 框架相关的**算法开发与代码实现**（Python / Lean4 / 其他），与 `10-模拟`（数值实验脚本）区分：

- `10-模拟`：验证性数值实验、参数扫描、图表生成
- `11-代码实现`：可复用的计算模块、推导工具、自动化脚本、形式化证明辅助

## 子目录建议

- `python/`：数值计算与符号推导（numpy / sympy / mpmath）
- `lean/`：Lean4 形式化证明辅助
- `scripts/`：工作区维护脚本（死链检查、引用同步等）
- `utils/`：共享工具函数

## 约定

- 每个脚本/模块注明：用途、依赖、输入/输出、对应 v3 章节或候选笔记
- 不在此目录存放文档（.md 文档归各研究分类目录）
- 代码产出若验证 v3 预言，结论以 v3 权威基准为准；验证候选笔记结论需标注冲突清单
