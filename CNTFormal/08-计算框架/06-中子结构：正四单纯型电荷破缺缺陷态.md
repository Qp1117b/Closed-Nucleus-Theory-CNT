# 中子结构：正四单纯型电荷破缺缺陷态

> **理论基础**：正四单纯型（4-simplex）电荷破缺假设——质子为基态占据，中子为同一单纯型的电荷破缺缺陷态。精细结构常数 $\alpha$ 的第一性计算以 [`归档/02-4-单纯形路径/`](../归档/02-4-单纯形路径/第一性原理计算：从4-单纯形几何到G与耦合常数.md) 为准，本文聚焦中子质量差、$\beta$ 衰变与寿命。
>
> **关联文档**：[`03-方法论/04`](../03-方法论/04-规范、群与标准模型：CNT视角与全景评估.md)（全景框架）、[`05-推导链`](../03-方法论/05-推导链.md)（推导链）

## 1. 质子 = 正四单纯型基态占据

正四单纯型（正则 4-simplex $\Delta_4$）具有 5 顶点、10 边、10 三角形面、5 四面体的组合结构。其对称群 $S_5$ 的不可约表示分解 $\mathbf{10} = \mathbf{1} \oplus \mathbf{4} \oplus \mathbf{5}$ 给出 Cartan 曲率本征值 $\{9,4,1\}$（见归档文档 §1.2）。

**质子 = 该单纯型的完整色-电荷单态占据**：
- 5 顶点对应质数序列 $2,3,5$ 的基底结构，经 SU(5) Weyl 对称性 $W_m = 5 \cdot 2^{m-1}$ 与 CNT 的 p 进扇区对应
- 10 条边对应耦合常数空间的独立通道数
- 拓扑结构无缺陷，总电荷 $Q = +1$ 由基态配置唯一确定
- 二面角 $\theta_4 = \arccos(1/4)$ 编码规范耦合的几何背景

> **CNT 对应**：质子的再生产稳定性 = 正四单纯型基态的拓扑刚性——单纯型的内禀几何约束锁定质子质量为实验值 $m_p$（作为 CNT 唯一量纲输入）。

---

## 2. 中子 = 电荷破缺缺陷态

**中子** = 同一正四单纯型的电荷破缺缺陷态：某一顶点发生 $u \leftrightarrow d$ 的局部翻转，破坏基态的电荷配置。

| 性质 | 质子（基态） | 中子（缺陷态） |
|---|---|---|
| 总电荷 | $+1$ | $0$（破缺中和） |
| 拓扑状态 | 完整 4-simplex | 含一个缺陷位 |
| 稳定性 | 稳定（能量最低） | 亚稳（$t_{1/2} \approx 880$ s） |
| 质量 | $m_p$ | $m_n > m_p$ |

**缺陷的几何图像**：正四单纯型的一个顶点在其电荷标签 $u \leftrightarrow d$ 上被翻转。由于电荷配置是单纯型内禀几何的一部分（不是外加的），此翻转改变了局部再生产频率 $v_\tau$，表现为拓扑张力。

### 几何-代数对应

| 几何（正四单纯型） | 代数（p 进 / adele / 质数动力学） |
|---|---|
| 5 顶点 | 质数序列 $2,3,5$ 的基底结构 |
| 10 条边 | 耦合常数空间的独立通道数 |
| 二面角 $\theta_4$ | p 进耦合常数的相位 / 赋值角度 |
| 电荷破缺缺陷位（中子） | 某 p 进通道的非平凡赋值异常 |
| 单纯型对称群 $S_5$ | Weyl 群对称性与质数置换的代数对应 |
| 拓扑张力（质量差） | 再生产频率差异 $\Delta v_\tau$ 的数值 |
| 缺陷修复（$\beta$ 衰变） | 再生产坍缩的代数跃迁 $u \leftrightarrow d$ |

## 3. 质量差：$m_n - m_p = 1.293$ MeV —— 第一性公式

### 3.1 公式

质量差 = 正四单纯型电荷破缺缺陷位的拓扑张力，由纯几何量与谱流常数表达：

$$
\boxed{m_n - m_p = 2 \cdot \theta_4 \cdot (1 - \alpha_5 C) \cdot C^2 \cdot m_p}
$$

其中 $\theta_4 = \arccos(1/4)$ 为正四单纯型二面角。

### 3.2 数值验证

| 量 | 数值 |
|---|---|
| $\theta_4 = \arccos(1/4)$ | $1.31811607$ rad |
| $2\theta_4$ | $2.63623214$ |
| $C = \xi'(1)/\xi(1)$ | $0.02309570897$ |
| $C^2 \cdot m_p$ | $0.50048$ MeV |
| $\alpha_5 C$ | $0.01960$（$\alpha_5^{\text{UV}} = 0.8485$） |
| $1 - \alpha_5 C$ | $0.98040$ |
| **公式值** | **$1.2935$ MeV** |
| PDG 实验值 | $1.29333$ MeV |
| **偏差** | **$+0.013\%$** |

### 3.3 物理来源

四项因子的物理意义：

| 因子 | 来源 | 类型 |
|---|---|---|
| $2$ | 电荷翻转对称性——$u \leftrightarrow d$ 的二重简并 | $S_5$ 对称性破缺 |
| $\theta_4 = \arccos(1/4)$ | 正四单纯型二面角——编码缺陷的拓扑扭转角度 | 几何不变量 |
| $C^2 \cdot m_p = 0.5005$ MeV | 谱流二阶量子——缺陷是 $v_\tau$ 涨落的二级效应 | 数论·谱几何 |
| $1 - \alpha_5 C$ | UV→IR RG 修正：从 GUT 标度流向电磁标度 | 重整化群 |

核心洞见：$\theta_4$ 与 Mathieu 特征值 $\lambda_c = 1.31602$ 相差仅 $0.16\%$（$\theta_4 - \lambda_c = 0.00209$），表明同一几何结构在谱理论（$\lambda_c$）和离散几何（$\theta_4$）中等效编码。无 RG 修正的领头项 $2\theta_4 C^2 m_p = 1.3194$ MeV（$+2.0\%$），$\alpha_5 C$ 修正是从 UV 到 IR 的自然谱流衰减。

### 3.4 公式的推导链

```
4-simplex 电荷破缺缺陷（u↔d 翻转）
    → 拓扑张力 = 二面角 θ₄ × 翻转对称性 2
    → 能量标度 = C²·m_p（谱流二阶，非一阶 C·m_p ≈ 21.7 MeV）
    → RG 修正 (1-α₅C) 连接 UV 几何与 IR 物理
    → m_n - m_p = 2θ₄·(1-α₅C)·C²·m_p
```

## 4. $\beta$ 衰变：缺陷修复

$\beta$ 衰变 $n \to p + e^- + \bar{\nu}_e$ 解读为正四单纯型缺陷位通过再生产坍缩自发修复的过程：

1. **触发**：缺陷位的拓扑张力使其在再生产时间尺度上不稳定
2. **过程**：顶点电荷翻转 $d \to u$ 的逆过程通过弱相互作用的 p 进通道实现
3. **产物**：$e^-$ 和 $\bar{\nu}_e$ 是电荷-轻子数守恒的补偿——缺陷修复释放的能量不足以产生更重粒子
4. **能量**：释放 $Q = m_n - m_p - m_e \approx 0.782$ MeV，与实验一致

**CNT 对应**：弱相互作用在此处不是"外力"，而是正四单纯型内禀对称性 $S_5$ 的破缺恢复通道。$\beta$ 衰变速率由 $W$ 玻色子质量（$M_W$）和缺陷拓扑结构共同决定。

## 5. 中子寿命 $\tau_n \approx 880$ s

中子寿命 = 缺陷位拓扑跃迁的再生产概率倒数：

$$
\tau_n \sim \frac{1}{\Gamma},\quad \Gamma \propto \exp\left(-\frac{\Delta E_{\text{topo}}}{k_B T_{\text{CNT}}}\right)
$$

其中 $\Delta E_{\text{topo}}$ 是缺陷位的拓扑能量壁垒，$T_{\text{CNT}}$ 是 CNT 的"再生产温度"（与谱流常数 $C$ 相关）。

**数量级估计**：
- 若 $\Delta E_{\text{topo}} \sim m_n - m_p \approx 1.3$ MeV
- 特征跃迁频率由 $C$（谱流步长）和 $M_W$（弱作用标度）给出
- $\tau_n \sim 10^3$ s 对应 $\Gamma \sim 10^{-3}$ s$^{-1}$ = 弱作用耦合平方 $g_w^2 \approx 0.4$ 乘以相空间因子

> **精确公式待建**：中子寿命的严格 CNT 公式需要缺陷拓扑结构（$S_5$ 破缺模式）与弱相互作用动力学（$W$ 玻色子传播）的完整耦合。此为开放问题。

## 附录：精细结构常数 $\alpha$ 的两条计算路径

参照归档文档（`归档/02-4-单纯形路径/第一性原理计算：从4-单纯形几何到G与耦合常数.md`）的记录，$\alpha$ 的第一性计算有两条独立路径：

**路径一：正四单纯型几何路径**
- 正四单纯型的几何不变量（二面角 $\theta_4 = \arccos(1/4)$、体积比、Schläfli 符号）编码耦合常数空间的结构
- 通过将 $\alpha$ 嵌入正四单纯型的内禀几何约束，从拓扑必然性导出 $\alpha$ 的数值
- 结果偏差：$\alpha^{-1} \approx 137.258$，与实验偏差 0.16%（见归档文档 §2）

**路径二：代数筛选路径**
- 通过 p 进赋值 / adele 结构对耦合常数进行数论约束
- 质数动力学 $u = \ln r$ 结合不确定性关系 $(\Delta r/\langle r\rangle) \cdot \Delta v_\tau \geq C/2$ 筛选允许的 $\alpha$ 值
- 边界条件 $\xi(s) = \xi(1-s)$ 的模约束锁定 $\alpha$ 的精确值

两条路径独立收敛到相近数值，构成交叉验证。几何路径在归档文档中完整记录，代数路径对应 `08-计算框架/01-数学化纲领` §5-6 的 adele 周期方法。
