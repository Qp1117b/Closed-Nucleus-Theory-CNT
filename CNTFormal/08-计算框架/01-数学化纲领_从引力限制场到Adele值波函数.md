## 1. 引言

标准模型有 19 个自由参数。量子引力方案（弦论、圈量子引力）在数学上高度发达，但在实验上不可证伪。这暗示了一个根本问题：**现有物理学的形式结构与其经验内容之间存在断裂**。

CNT 的出发点是：物理学是关于**再生产**的科学——物质如何维持自身、如何产生剩余、如何在层级间转化。从物质的运动形式出发，建立数学结构。

**结构选择声明**：CNT 的数学推导从以下不可还原的结构选择出发：
1. **最小大统一群 SU(5)**：作为秩为 4 的最简单大统一群，其 Weyl 群和 Cartan 子代数结构提供了角向量子数与粒子表示的对应。
2. **三代结构**：角向求和截断于 $m \leq 3$，对应 SU(5) 的基本不可约表示（$\bar{5}, 10, 24$）的独立 Weyl 轨道。$m=4$ 对应可约表示 $40 = 24 \oplus 10 \oplus \bar{5} \oplus 1$，不被独立枚举。
3. **自然单位制** $\hbar = c = 1$：标准约定，所有量纲以能量（GeV）为基准。
4. **黎曼假设**：作为工作假设（working hypothesis），与弦论采用卡拉比-丘紧致化、圈量子引力采用自旋网络作为工作假设处于同等方法论地位。在数学上，$C = \xi'(1)/\xi(1)$ 的值不依赖黎曼假设（可通过 $\xi$ 的 Hadamard 乘积直接计算），但级数表示 $\sum (1/4+\gamma_n^2)^{-1}$ 需要零点在临界线上。若未来黎曼假设被证伪，CNT 的谱结构需要相应修正，但元 RG 框架本身不依赖此假设。

## 2. 本体论 → 代数结构

### 2.1 三原则

**原则 I（过程优先）**：存在不是实体，而是再生产循环。基本对象是**再生产循环**——维持自身因果结构的过程。

**原则 II（限制场）**：引力不是相互作用，而是**元条件**。它约束所有再生产循环的因果序，是"因果之因果"的结构性前提。
> **框架结构导读（候选链第 5 份八层总览，经筛选）**：CNT 统一动力学可概括为八层——(1) 限制场（元条件）tau_res = hbar/(M_eff c^2)；(2) 运动学（一阶传输方程）；(3) 动力学（二阶薛定谔）；(4) 全局自守（Psi(qx)=Psi(x), xi(s)=0）；(5) p进结构（Hecke）；(6) 费曼图（Bruhat-Tits 树）；(7) 路径积分（adele）；(8) 物理预言（Lambda_QCD, G_N, alpha^-1, sin^2 theta_W 等）。注意：第 (8) 层 alpha^-1 严格导出仍为开放问题（§7.5），m_H 在本框架中尚未推导，不得以"已涌现"视之。

**原则 III（层级一致性）**：微观层级的代数结构必须能推出宏观层级的几何结构。层级断裂不是神秘的，而是**系综平均**的必然结果。

### 2.2 三个不可还原公理 + 一个启发性约束

**公理 I（辛-动力学结构）**：耦合常数空间 $(u, p_u)$（其中 $u = \ln r$，$r$ 为无量纲耦合强度）构成辛流形，其量子化由标准对易子生成：
$$[\hat{u}, \hat{p}_u] = i \quad (\hbar = 1)$$

壳层空间的双曲几何 $ds^2 = du^2 + e^{-2u}d\theta^2$（Poincaré 上半平面）自然给出基本动力学算符：
$$\boxed{\hat{H} = \hat{D}^2 + \frac{1}{4}, \quad \hat{D} = -i\left(\partial_u - \frac{1}{2}\right)}$$

这是 CNT 的**基本动力学方程**（标准微分几何，严格）：
$$i\partial_\tau \Psi = \hat{H}\Psi$$

**公理 II（辛拓扑量子化）**：再生产循环作为辛流形上的闭合轨道，其最小非平凡周期包围的辛面积为 $2\pi$（Berry-Keating 单位胞条件 [Berry & Keating, SIAM Rev. **41**, 236 (1999)]）。此拓扑要求与耦合常数空间的硬壁边界条件自洽地确定截断尺度。

**公理 III（全局-数论谱）**：物理世界的全局因果结构由 Adele 类空间 $\mathbb{A}^\times/\mathbb{Q}^\times$ 描述。其谱约束由 Tate 积分给出，非平凡谱点由黎曼 $\xi$ 函数的非平凡零点 $\{s_n = 1/2 + i\gamma_n\}$ 枚举。

**启发性约束 χ（再生产幂等性）**：
$$\boxed{\chi(u, p_u) = p_u - \frac{Ce^u - 1}{2} = 0}$$


**公理 IV（能标-固有时对易子）**：
$$[\hat{\tau}, \hat{u}] = iC$$

### 2.3 定理 2.X（传输方程——约束壳运动学）

**定理**：**若**约束 $\chi=0$ 成立，即 $p_u = (Ce^u-1)/2$，则从哈密顿方程 $du/d\tau = 2p_u+1$ 直接给出特征线方程 $du/d\tau = Ce^u$。特征线法给出传输方程：
$$\boxed{\partial_\tau \Psi + C e^u \partial_u \Psi = 0}$$

**严格性等级**：传输方程本身是一阶双曲型方程的标准理论（若约束成立则严格）。但约束 $\chi=0$ 的推导是启发式的（从 $\mu\circ\mu=\mu$ 的范畴论类比跳跃到相空间约束 $\chi=0$，无严格数学步骤）。

**身份**：传输方程是**约束壳上的导出运动学**，不是独立的基本方程。它描述经典 RG 流特征线 $dr/d\tau = C r^2$，是实时数、无相位、无干涉的经典极限。

### 2.4 定理 2.2（Berry-Keating 截断）

**定理**：公理 II 与公理 III 的函数方程对称性联合确定硬壁截断 $L = \pi/2$。

**证明**：公理 II 要求最小闭合轨道的辛面积为 $2\pi$。对于硬壁截断 $u \in [-L, L]$，基态轨道在相空间 $(u, p_u)$ 中包围的矩形面积为 $2L \cdot (\pi/L) = 2\pi$（其中 $p_u$ 的基态跨度 $\Delta p_u = \pi/L$ 来自驻波量子化 $k_1 = \pi/L$）。此恒等式对任意 $L$ 成立，但结合公理 III 的函数方程 $\xi(s) = \xi(1-s)$（即 $u \leftrightarrow -u$ 的 UV-IR 对偶），要求边界对称 $u_{\max} = -u_{\min} = L$。Berry-Keating 的半经典零点计数 $N(E) \sim (E/2\pi)\ln(E/2\pi)$ 与硬壁盒子的态密度匹配，自洽地确定 $L = \pi/2$。∎

### 2.5 定理 2.3（硬壁边界）

**定理**：耦合常数空间 $u \in [-\pi/2, \pi/2]$。

**证明**：从定理 2.X，传输方程的特征线 $du/d\tau = C e^u$ 在 $u \to +\infty$ 处于有限 $\tau$ 发散（UV 奇点），在 $u \to -\infty$ 处冻结（IR 渐近行为）。因此物理上耦合常数空间必须有有限范围。公理 II 的辛量子化要求硬壁边界以正则化 UV 奇点，IR 端则由 $e^u \to 0$ 的自然冻结提供软截断。结合定理 2.2 的 $L=\pi/2$，得 $u \in [-\pi/2, \pi/2]$。∎

### 2.6 不确定性关系

**定理 2.1（标量不确定性关系）**：从约束壳推论 $[\hat{\tau}, \hat{u}] = iC$ 导出：
$$\boxed{\Delta\tau \cdot \Delta u \geq \frac{C}{2}}$$

等价于耦合常数空间的标量形式：
$$\boxed{\frac{\Delta r}{\langle r\rangle} \cdot \Delta \tau \geq \frac{C}{2}}$$

其中 $v_\tau = du/d\tau = C e^u$ 为固有时流速。

## 3. 动力学方程与 RG 流

### 3.0 动力学层次总览

CNT 的动力学结构分为三个层次：

$$\boxed{\text{层次 I: } \hat{H} = \hat{D}^2 + \frac{1}{4} \quad\text{（基本量子动力学，严格）}}$$

$$\boxed{\text{层次 II: } \chi(u,p_u) = p_u - \frac{Ce^u-1}{2} = 0 \quad\text{（再生产约束，启发式）}}$$

$$\boxed{\text{层次 III: } \partial_\tau\Psi + Ce^u\partial_u\Psi = 0 \quad\text{（约束壳运动学，若 }\chi=0\text{ 则严格）}}$$

**关键事实**：CNT 的所有定量预言来自层次 I（$E_n = 1/4+\gamma_n^2$, $\lambda_c$, β 函数谱等）。层次 III（传输方程）仅提供 $\tau \leftrightarrow \ln\mu$ 的物理解释（RG 字典），不直接参与定量计算。

### 3.1 约束壳上的经典运动

**定理 3.1**：经典哈密顿量 $H_{\text{cl}} = p_u^2 + p_u$ 在约束壳 $\chi=0$ 上给出特征线方程：
$$\frac{du}{d\tau} = Ce^u$$

WKB 极限下的波动力学方程（若约束壳的量子化是合法的）：
$$\partial_\tau \Psi + C e^u \partial_u \Psi = 0$$

### 3.2 特征线 = RG 流

**定理 3.2**：特征线方程 $du/d\tau = -C e^u$ 的解：
$$u(\tau) = -\ln(-C\tau + \text{const}), \quad r(\tau) = \frac{1}{-C\tau + \text{const}}$$

### 3.3 CNT–标准 RG 精确字典

**定理 3.3**：标准 QFT 的单耦合 RG 方程 $dg/dt = -\beta_0 g^3$（$t = \ln(\mu/\Lambda)$）的解为 $g^2(t) = 1/(\beta_0 t)$。CNT 的 $r = g^2$ 对应给出：
$$\tau = \frac{C}{2\beta_0} \cdot \ln\frac{\mu}{\Lambda}$$

**物理意义**：因果时 $\tau$ 作为元条件不依赖特定相互作用，但 RG 流在特定规范群中的速率由 $\beta_0$ 决定。比例因子 $C/(2\beta_0) \approx 0.056$（SU(5)）将普适的因果时转换为具体的 RG 标度。

### 3.4 p进 RG 方程

**定理 3.4**：在 $p$ 进位点 $\mathbb{Q}_p$，耦合赋值 $|g_p|_p = p^{-k}$（$k \in \mathbb{Z}$）是离散的，RG 流成为离散跳跃：
$$k \to k - 1 \quad \text{当} \quad \Delta\tau = \frac{\ln p}{C}$$

定义 **p进再生产周期**：
$$\Delta\tau_p = \frac{\ln p}{C}$$

### 3.5 球坐标分解

**公理 3.2**（结构选择）：耦合常数空间采用自然球坐标：
- 径向 $u = \ln r$：总耦合强度
- 角向 $(\theta, \phi)$：规范对称性取向

**注**：此球坐标**不在物理时空中**，而在抽象的辛流形中。物理时空的曲率不直接破坏此内部对称性，因为两者层级解耦。

### 3.6 Dirac 量子化不自洽问题

**问题陈述**：约束 $\chi(u, p_u) = 0$ 在经典哈密顿力学中合法。但在量子力学中，约束必须提升为算符方程 $\hat{\chi}|\Psi\rangle = 0$，这要求约束壳 $\text{Ker}(\hat{\chi})$ 在动力学演化下不变。然而：
$$\boxed{[\hat{H}, \hat{\chi}] = Ce^u \partial_u \neq 0}$$

这意味着 $\hat{H}$ 将态矢量移出约束壳：若 $|\Psi\rangle \in \text{Ker}(\hat{\chi})$，则 $\hat{H}|\Psi\rangle \notin \text{Ker}(\hat{\chi})$ 一般成立。Dirac 约束量子化的标准结构（"第一类约束 → 物理态条件"）在此处不适用。

**数学根源**：
- $\hat{H} = -\partial_u^2 + \partial_u$ 是二阶微分算符
- $\hat{\chi} = -i\partial_u - (Ce^u-1)/2$ 是一阶微分算符
- $\hat{H}$ 在约束壳上的限制不是自伴的，因为 $\hat{\chi}$ 不是 $\hat{H}$ 的不变子空间

**两条可能的前进路径**：

| 路径 | 方案 | 代价 |
|:---|:---|:---|
| **路径 1：Dirac 括号** | 将 $\chi=0$ 提升为第二类约束，用 Dirac 括号替换泊松括号 | 需构造完整的约束代数，引入额外的第二类约束使系统可解 |
| **路径 2：约束壳仅用于 WKB 极限** | $\chi=0$ 仅在 $\hbar \to 0$ 极限（WKB/经典）中严格成立；量子层面只用 $\hat{H} = \hat{D}^2+1/4$ | 传输方程失去量子力学基础，仅为半经典近似 |
| **路径 3：Bethe Ansatz 验证** | 用 $\hat{H} = \hat{D}^2+1/4$ 的精确对角化解直接验证计算预言，不依赖约束壳 | 约束 χ=0 及其推论（$[\hat{\tau},\hat{u}]=iC$）仅保留为物理启发，不进入定量推导 |

**当前选择**：**路径 3**。CNT 的定量预言全部来自 $\hat{H} = \hat{D}^2+1/4$ 的谱结构（定理 4.1）。传输方程及其推论仅作为 RG 流物理解释的启发框架。路径 1（Dirac 括号严格化）是攻关方向，但当前不影响计算结果。

### 3.7 总结：动力学方程的严格性层次

| 方程 | 身份 | 严格性 | 计算依赖 |
|:---|:---|:---|:---|
| $\hat{H} = \hat{D}^2 + 1/4$ | 基本量子动力学 | ✅ 严格（微分几何） | 全部定量预言 |

## 4. 黎曼谱与边界条件

### 4.1 硬壁截断

**定理 4.0**：$u \in [-L, L]$，驻波量子化 $k_n = \pi n / L$（从定理 2.2，$L=\pi/2$，$k_n = 2n$）。

### 4.2 函数方程对称性

**定理 4.1**：全局波函数继承 $\xi$ 函数的函数方程对称性：
$$\psi(r) = r^{-1}\psi(1/r) \cdot e^{i\chi}$$

**证明**：公理 III 中 Tate 积分 $\xi(s) = \int_{\mathbb{A}^\times/\mathbb{Q}^\times} |x|_{\mathbb{A}}^{-s} d^\times x$ 满足函数方程 $\xi(s) = \xi(1-s)$。在物理上，$|x|_{\mathbb{A}} \leftrightarrow |x|_{\mathbb{A}}^{-1}$ 对应 $r \leftrightarrow 1/r$（即 $u \leftrightarrow -u$）。全局波函数 $\Psi_n$ 必须继承此对称性，故 $\psi(r) = r^{-s_n}\psi(1/r)r^{s_n-1} \cdot \text{(相位)}$。对于 $s_n = 1/2 + i\gamma_n$，模平方给出 $|\psi(r)|^2 = r^{-1}|\psi(1/r)|^2$。引入相位因子 $e^{i\chi}$ 后得定理形式。∎

### 4.3 临界线模式筛选

**定理 4.2**：非临界线模式获得虚部能级，破坏概率守恒，从而违反原则 III（层级一致性）。因此物理上仅允许临界线模式 $s_n = 1/2 + i\gamma_n$。

**定理 4.1（第一性谱公式）**：径向能级从壳层空间双曲 Laplacian $\hat{H} = \hat{D}^2 + 1/4$（$\hat{D} = -i(\partial_u - 1/2)$）在自守边界条件下严格导出，等于临界线零点模平方：
$$\boxed{E_n = \rho_n(1-\rho_n) = \frac14 + \gamma_n^2}$$

其中 $\rho_n = 1/2 + i\gamma_n$ 为黎曼临界线零点（定理 4.2）。此式即 $\rho_n(1-\rho_n) = |\rho_n|^2 = 1/4 + \gamma_n^2$，为双曲 Laplacian 本征值。

**注**：$E_n = 1/4+\gamma_n^2$ 已从壳层双曲几何严格导出（2026-07-21）。

### 4.4 核心解析恒等式

**定理 4.3**：
$$\boxed{C = \sum_{n=1}^\infty \frac{1}{\frac{1}{4} + \gamma_n^2} = \frac{\xi'(1)}{\xi(1)} = 1 + \frac{\gamma}{2} - \frac{1}{2}\ln(4\pi) \approx 0.023095708966}$$

**注 4.1（关于黎曼假设）**：CNT 采用黎曼假设作为工作假设。在数学上，$C = \xi'(1)/\xi(1)$ 的值不依赖黎曼假设（可通过 $\xi$ 的 Hadamard 乘积直接计算），但级数表示 $\sum (1/4+\gamma_n^2)^{-1}$ 需要零点在临界线上。

## 8. 角向谱与分类定理

### 8.1 角向马蒂厄方程（精确解）

**定理 8.1（CNT 线）**：从公理 I 的角向辛结构 $[\hat{\theta}, \hat{p}_\theta] = i$ 和 SU(5) 的 Cartan 子代数几何，角向势能的主导项为 $V(\theta) \propto \sin^2(z)$（$z = \theta - \theta_{\text{GUT}}$），马蒂厄方程参数满足 $a = 2q$。

**证明**：SU(5) 根空间中，温伯格角 $\theta_W$ 的势能由两个 Cartan 方向的非对易性决定。在 GUT 标度（$\theta = \theta_{\text{GUT}}$），势能最小（对称性恢复）。偏离 GUT 时，主导项为 $V(z) \propto \sin^2(z)$。展开 $\sin^2(z) = (1-\cos(2z))/2$，对比标准 Mathieu 方程 $y'' + [a - 2q\cos(2z)]y = 0$，得 $a = \lambda/2$，$2q = \lambda/2$，因此 $a = 2q$。∎

**公理 8.1**（现为定理）：$\psi'' + \lambda \sin^2(z)\psi = 0, \quad z \in [0, \pi/2]$

等价于标准 Mathieu 方程在**特征线** $a = 2q$（即 $a = \lambda/2$, $q = \lambda/4$）上的本征值问题。不同 SU(5) 表示对应不同的边界条件：

| $m$ | SU(5) | 边界条件 | Mathieu 曲线 | $\lambda_m$ |
|-----|-------|----------|-------------|-------------|
| 1 | $\bar{5}$ | DN（Dirichlet at $0$, Neumann at $\pi/2$） | $b_1(q)$ | **1.3160229113** |
| 2 | $10$ | ND（Neumann at $0$, Dirichlet at $\pi/2$） | $a_1(q)$ | **3.5592799753** |
| 3 | $24$ | DD（Dirichlet at $0$, Dirichlet at $\pi/2$） | $b_2(q)$ | **7.4328467659** |

这些是本征值在 CNT 线上的**精确数值解**，由连分数方程严格确定。

### 8.3 分类定理（已确立）

**定理 8.3（三代截断）**：角向量子数 $m$ 与 SU(5) 的不可约基本表示的 Weyl 轨道存在严格的枚举对应：
$$\boxed{W_m = 5 \times 2^{m-1}}$$

| $m$ | $W_m$ | SU(5) 表示 | 类型 | 标准模型内容 |
|-----|-------|-----------|------|-------------|
| 1 | 5 | $\bar{5}$ | 基本 | $d^c + L$ |
| 2 | 10 | $10$ | 基本 | $Q + u^c + e^c$ |
| 3 | 20 | $24$（非零根） | 基本 | $G + W + B + X + Y$ |
| 4 | 40 | $40 = 24 \oplus 10 \oplus \bar{5} \oplus 1$ | **可约** | 不独立枚举 |

**证明**：
1. SU(5) 的不可约表示维度由最高权决定。基本表示的维度序列：$5, 10, 15, 24, 35, 40, \dots$
2. $40$ 维表示不是基本表示：$40 = 24 \oplus 10 \oplus \bar{5} \oplus 1$（张量积分解）。

## 9. 能动张量与爱因斯坦方程涌现

### 9.1 代数能动张量

**公理 9.1**：
$$\hat{T}_{\mu\nu}^{\text{代数}} = \frac{1}{2}\left(\{\hat{p}_u, \partial_\mu \hat{u}\} \partial_\nu \hat{u} + \partial_\mu \hat{u} \{\hat{p}_u, \partial_\nu \hat{u}\}\right) - \eta_{\mu\nu} \hat{\mathcal{L}}$$

### 9.2 系综平均

**定理 9.1（守恒律）**：
$$\nabla^\mu \langle T_{\mu\nu} \rangle = 0$$

**证明**：从传输方程的概率守恒 $\partial_\tau |\Psi|^2 + C e^u \partial_u |\Psi|^2 = 0$ 出发，定义概率流 $J_u = C e^u |\Psi|^2$。海森堡方程给出：
$$i\partial_\tau \hat{T}_{\mu\nu} = [\hat{H}, \hat{T}_{\mu\nu}] = C e^{\hat{u}} [\hat{p}_u, \hat{T}_{\mu\nu}]$$

对 $\hat{T}_{\mu\nu}$ 的显式表达式计算对易子：
$$[\hat{p}_u, \partial_\mu \hat{u}] = -i \partial_\mu \partial_u \hat{u} = -i \partial_\mu (1) = 0$$
（因为 $u$ 是坐标算符，$\partial_u u = 1$）。因此 $[\hat{H}, \hat{T}_{\mu\nu}]$ 的反对称部分正比于 $\partial_\mu \hat{u} \partial_\nu \hat{u} - \partial_\nu \hat{u} \partial_\mu \hat{u} = 0$。在系综平均 $\langle \cdot \rangle$ 下，量子涨落项 $\langle \delta \hat{T}_{\mu\nu} \rangle$ 因各向同性而消失。限制场映射 $(u,\tau) \to x^\mu$ 将偏导数提升为协变导数，得到 $\nabla^\mu \langle T_{\mu\nu} \rangle = 0$。∎

### 9.3 爱因斯坦方程

**定理 9.2（涌现）**：
$$G_{\mu\nu} = \kappa \langle T_{\mu\nu} \rangle$$

其中 $\kappa = 8\pi G$ 的标度结构为：
$$\kappa = \frac{C_\theta}{C} \cdot \frac{1}{m_p^2} \cdot \mathcal{N}_{\text{层级}}$$

**修正**：在自然单位制（$\hbar = c = 1$）下，$\mathcal{N}_{\text{层级}} = 1$ 是 Adele 体积标准归一化的直接结果。真正需要解释的是 $g_s^{\text{IR}}$ 的冻结值，而非 $\mathcal{N}_{\text{层级}}$。

$$\boxed{1 - 3q = \frac{q^2}{9-2q - \frac{q^2}{25-2q - \frac{q^2}{49-2q - \cdots}}}}$$

## 11. 方法论教训

### 11.1 关于"勒让德符号修正因子"的教训

曾试图用数论特征标（Legendre/Jacobi 符号）的累积效应修正 $\sin^2\theta_W$ 从 0.300 到 0.231。数论检验全部否决：

- Jacobi 符号 $(n|m)$ 在 $n$ 上平均 $\to 0$
- von Mangoldt 加权 $\sum \Lambda(n)\chi(n)/\sum\Lambda(n) \to 0$

**教训**：CNT 框架内生的修正（角向传输方程给出 0.231）优先于外部数论构造。

### 11.2 关于"平凡零点修正"的教训

$\xi(s)$ 的零点只有非平凡零点。$\zeta(s)$ 在负偶数处的"平凡零点"被 $\Gamma(s/2)$ 在同一点的极点精确抵消。**"平凡零点修正项"在数学上不存在。**

### 11.3 关于"马蒂厄本征值公式"的教训

$\lambda_m$ 的精确表达式由连分数方程严格确定，解析近似 $\lambda_m = \pi^2(m+1/4)^2$ 与数值解偏差超过 100%（$m=1$）。

### 11.4 关于 $v_g^{(1)}=1$ 的教训

## 12. 球极方程与循环方程的区分

**注 12.1（坐标空间与相空间）**：本文中的耦合常数空间采用球坐标 $(u, \theta, \phi)$，但元 RG 方程不是标准球坐标方程。标准球坐标方程（球极方程）描述物理空间中的连续流动；循环方程（元 RG 传输方程）描述循环论相空间中的再生产循环。

### 12.1 球极方程（标准球坐标方程）

球极方程是标准连续性方程在球坐标下的形式：
$$\partial_t \rho + \frac{1}{r^2}\partial_r(r^2 v_r \rho) + \frac{1}{r\sin\theta}\partial_\theta(\sin\theta \cdot v_\theta \rho) + \frac{1}{r\sin\theta}\partial_\phi(v_\phi \rho) = 0$$

**特征**：
- $v_r, v_\theta, v_\phi$ 由具体动力学决定
- 一般情况下三个分量均非零
- 描述耦合常数在三维空间中**任意方向自由跑动**
- 标准模型 RGE 中 $\theta_W$ 随能标连续变化即属此类

### 12.2 循环方程（CNT 元 RG 方程）

循环方程是循环论相空间中的传输方程。循环论相空间由**三个耦合常数坐标** $(g_1, g_2, g_3)$ 和**一个内禀固有时** $\tau$ 构成：
$$\text{循环论相空间} = (g_1, g_2, g_3, \tau)$$

通过坐标变换 $u = \ln\sqrt{g_1^2+g_2^2+g_3^2}$，$\theta = \arctan\frac{\sqrt{g_2^2+g_3^2}}{g_1}$，$\phi = \arctan\frac{g_3}{g_2}$，循环方程在球坐标下写为：
$$\partial_\tau \Psi + C e^u \partial_u \Psi = 0, \quad v_\theta = v_\phi = 0$$

**在直角坐标 $(g_1, g_2, g_3)$ 下**：
$$\partial_\tau \Psi + C \sqrt{g_1^2+g_2^2+g_3^2} \sum_{i=1}^3 g_i \partial_{g_i} \Psi = 0$$

**特征**：
- 径向分量 $v_r = C e^u$（元 RG 驱动）
- 角向分量 $v_\theta = v_\phi = 0$（**无自由跑动**）
- 描述耦合常数**沿固定方向等比例缩放**
- 方向 $(g_1:g_2:g_3)$ 冻结，径向跑动通过角向量子化修正实现离散跳跃

### 12.3 核心区别

| 维度 | 球极方程 | 循环方程 |
|------|---------|---------|
| **空间** | 标准球坐标空间（物理位置） | 循环论相空间（耦合常数 + 固有时） |
| **时间** | 物理时间 $t$ | 内禀固有时 $\tau$（元 RG 参数） |
| **角向行为** | $v_\theta, v_\phi$ 一般非零 | **严格为零**（量子化约束） |
| **覆盖性** | 特征线可覆盖全空间 | 方向冻结，径向等比例缩放 |
| **量子化** | 边界条件量子化 | Berry-Keating 单位胞 + 马蒂厄方程 |
| **物理** | 连续弥散 | 离散量子化跳跃 |

### 12.4 为什么 CNT 使用循环方程而非球极方程？

球极方程假设耦合常数可以在三维空间中**任意方向自由跑动**（如标准模型 RGE 中 $\theta_W$ 随能标连续变化）。

循环方程通过"无自由跑动"条件（$v_\theta = v_\phi = 0$）将耦合常数的**方向冻结**在 GUT 统一方向，径向跑动通过**角向量子化修正**（$\delta\theta_W^{(1)}, \rho_m$）实现离散跳跃。

这不是坐标变换的数学结果，而是**物理假设**——再生产循环的内部结构不允许规范对称性取向自由演化，只能通过量子化跃迁改变。
