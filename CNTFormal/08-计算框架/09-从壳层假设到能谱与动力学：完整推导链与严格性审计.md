## 一、根基：耦合壳层假设

**假设**：质子/闭合核的内部结构空间是 **Poincaré 半平面**（常负曲率 $K=-1$ 的双曲空间）

$$ds^2 = du^2 + e^{-2u}d\theta^2$$

| 坐标 | 物理身份 |
|:---|:---|
| $u = \ln r$ | 总耦合强度（对数径向） |
| $\theta$ | 规范对称性取向角（色荷/弱同位旋/电荷相位） |

**三个耦合方向**（$p=2,3,5$）各自形成独立壳层：$p=2$ 为 SU(3) 色动力学扇区，$p=3$ 为 SU(2) 弱同位旋扇区，$p=5$ 为 U(1) 电磁扇区。经层析论投影叠加为质子为中心的同心壳层图像。

**状态**：⚠️ **启发式假设**——度规不是从再生产逻辑 $\mu\circ\mu=\mu$ 严格涌出的，是CNT的**几何输入**。

### 1.1 假设的动机（非推导）

- 耦合常数跑动天然是乘性的（$g \to g'$），对数坐标 $u = \ln r$ 自然
- 三个耦合方向（强/弱/电磁）共用一个径向坐标 $u$
- 每个方向有独立的角向取向 $\theta$，共形因子 $e^{-2u}$ 体现"径向位置决定角向视尺度"
- 双曲几何的负曲率是 CNT 各向异性驱动（$\beta_1 \neq \beta_2 \neq \beta_3$）的几何根源

### 1.2 严格性

| 方面 | 状态 |
|:---|:---|
| 度规形式 | ⚠️ 启发式——有物理动机但非推导 |
| 坐标解释 | ⚠️ 物理直觉——$u=\ln r$ 的成功后验验证了选择 |
| 从再生产涌出 | ❌ 未证明——CNT最大结构性缺口 |

> **→ 展开链**：此假设是所有后续推导的**唯一几何输入**。链中其他所有结构（$\hat{H}$, $\hat{\mathcal{G}}$, $\hat{\mu}$）均从此度规和 Poincaré 测度 $d\mu = e^{-u}du\,d\theta$ 导出。度规的"为什么"问题在 §九 中作为核心张力讨论。与缺口5（$\mu\circ\mu=\mu \to \chi=0$，见 [08-五缺口全部攻克总结_v2.md §缺口5](file:///d:/WorkSpace/物理/闭合核理论/CNTFormal/08-计算框架/08-五缺口全部攻克总结_v2.md)）是同一根源的两个侧面：**度规是几何输入，χ=0是相应的经典约束——两者都尚未从再生产严格涌出。**

## 二、第一步：壳层几何 → 哈密顿量（严格）

从度规读出 Laplace-Beltrami 算子，构造：

$$\boxed{\hat{H} = \hat{D}^2 + \frac{1}{4}, \quad \hat{D} = -i\left(\partial_u - \frac{1}{2}\right)}$$

### 2.1 推导（纯微分几何）

1. Poincaré 半平面上的 Laplace-Beltrami 算子：
   $$\Delta_{\mathbb{H}^2} = e^{2u}(\partial_u^2 + \partial_\theta^2)$$

2. 测度 $d\mu = e^{-u}du\,d\theta$ 要求对称算子含偏移。定义 $\hat{D} = -i(\partial_u - 1/2)$，验证：
   $$\langle \hat{D}\phi, \psi \rangle_\mu = \int \overline{(-i(\partial_u-1/2)\phi)}\psi \cdot e^{-u}du d\theta = \langle \phi, \hat{D}\psi \rangle_\mu$$
   偏移 $1/2$ 来自 $\partial_u(e^{-u}) = -e^{-u}$ 的分部积分抵消。

3. 构造 $\hat{H} = \hat{D}^2 + 1/4$。$1/4$ 来自 $\hat{D}^2$ 展开中的常数项 $(i/2)^2 = -1/4$，加回 $1/4$ 确保 $\hat{H}$ 的谱有简单的 $1/4 + \gamma^2$ 形式。

**自伴性**：由 Nelson 解析向量定理，$\hat{H}$ 在 $C_c^\infty(\mathbb{H}^2)$ 上关于 $L^2(e^{-u}du\,d\theta)$ 本质自伴。**这是论文定理 2.1，纯微分几何，非猜测。**

### 2.2 为什么 $\hat{H} = \hat{D}^2 + 1/4$ 而非直接用 $\Delta_{\mathbb{H}^2}$？

直接使用 $\Delta_{\mathbb{H}^2} = e^{2u}(\partial_u^2 + \partial_\theta^2)$ 的问题：
1. 不是常系数算子（含 $e^{2u}$ 因子），谱无简单闭形式
2. 变换到 $\hat{D}$ 基后，$1/2$ 偏移使测度因子 $e^{-u}$ 被吸收，得到常系数结构
3. **这是黎曼零点 $1/4 + \gamma_n^2$ 进入物理的唯一入口**——任何其他偏移量都不给出此谱形式

### 2.3 严格性

| 方面 | 状态 |
|:---|:---|
| $\hat{D}$ 构造 | ✅ 严格——从度规和测度导出 |
| $\hat{D}$ 对称性 | ✅ 严格——分部积分验证 |
| $\hat{H}$ 自伴性 | ✅ 严格——Nelson解析向量定理（论文定理2.1） |

## 三、第二步：全局幺正 → 动力学方程（猜测）

**约束**：再生产计数 $\tau$ 的演化必须**全局概率守恒**（信息不丢失，只转移——CNT 核心公理，命题①-④，见 `CNT_核心论断终稿.md` §1）

**筛选**：所有非酉候选被排除：

| 候选 | 酉性 | 判定 |
|:---|:---|:---|
| $\hat{\mathcal{G}} = C e^{\hat{u}/2}\hat{D}e^{\hat{u}/2}$ | ✅ 自伴 → 酉半群 | **唯一幸存** |
| Lindblad 型 | ❌ 需要环境（整体非酉） | 排除 |
| 随机SDE | ❌ 非酉 | 排除 |
| 分数阶 $\partial_u^\alpha$ | ❌ 一般非自伴 | 排除 |
| 非线性Schrödinger | ❌ 破坏叠加原理 | 排除 |

**唯一幸存者**：

$$\boxed{i\partial_\tau \Psi = \hat{\mathcal{G}}\Psi, \quad \hat{\mathcal{G}} = C e^{\hat{u}/2}\hat{D}e^{\hat{u}/2} = -i C e^{\hat{u}}\partial_u}$$

### 3.1 $\hat{\mathcal{G}}$ 的自伴性（严格）

在 Poincaré 测度下分部积分：

$$\langle \phi, \hat{\mathcal{G}}\psi \rangle_\mu = -iC\int \bar{\phi}\partial_u\psi\, du d\theta = iC\int (\partial_u\bar{\phi})\psi\, du d\theta = \langle \hat{\mathcal{G}}\phi, \psi \rangle_\mu$$

因此 $\hat{\mathcal{G}}^\dagger = \hat{\mathcal{G}}$。由 Stone 定理，$e^{-i\hat{\mathcal{G}}\tau}$ 是强连续酉半群。**此证明是严格的**——算子形式的自伴性不依赖于 $\hat{\mathcal{G}}$ 的物理起源。

### 3.2 为什么是猜测？

$\hat{\mathcal{G}}$ 的形式是从筛选中选出的，但：
1. 筛选非穷举——是否存在其他自伴候选？未证明
2. $\hat{\mathcal{G}}$ 与再生产算符 $\hat{\mu}$ 的关系？$[\hat{\mu}, \hat{\mathcal{G}}]$ 未计算
3. 常数 $C$ 为何出现在这里？从 $[\hat{\tau}, \hat{u}] = iC$ 导入，见下方展开链

## 四、第三步：动力学方程 → 传输方程（严格代数）

直接代入 $\hat{\mathcal{G}}$：

$$i\partial_\tau \Psi = -i C e^u \partial_u \Psi \quad\Rightarrow\quad \boxed{\partial_\tau \Psi + C e^u \partial_u \Psi = 0}$$

**严格性**：✅ **代数恒等**，无近似。传输方程本身是严格的一阶线性PDE。

### 4.1 特征线 → RG流

$$\frac{du}{d\tau} = C e^u \;\Rightarrow\; \frac{dr}{d\tau} = C r^2 \;\Rightarrow\; r(\tau) = \frac{1}{K - C\tau}$$

其中 $r = e^u$ 是原始耦合强度。解在 $\tau = K/C$ 处发散——对应色禁闭的 IR 极点。

**物理**：这是 CNT 版 Gell-Mann-Low 方程。在 WKB 近似下，$\hat{H}$ 的 Schrödinger 流约化为传输方程特征线。

### 4.2 从 RG 流到 β 函数（全部第一性原理）

特征线 $du/d\tau = Ce^u$ 在三个素数扇区分别给出 β 函数（详细推导见 `CNT_RG_complete_derivation.py` §1-3）：

$$\beta_1 = -\frac{C}{q_c} = -0.070199, \quad \beta_2 = \frac{C}{I_{\text{SU2}}}, \quad \beta_3 = \frac{\lambda_c}{N_X \cdot I_{\text{SU3}}}$$

其中 $q_c = \lambda_c/4$ 是 Mathieu 连分数根（定理 4.1），$I_{\text{SU2}}$ 和 $I_{\text{SU3}}$ 是 SU(5) Dynkin 指数比。**三个 β 函数全部无自由参数。**

| 特征线解 | ✅ 严格——一阶线性PDE标准理论 |
| RG流物理解释 | ✅ 合理——与 Gell-Mann-Low 方程结构一致 |
| $\beta_i$ 推导 | ✅ 第一性——全部无自由参数 |
