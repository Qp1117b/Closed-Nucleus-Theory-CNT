# 可观测量公式（用户推导）：电荷、β、中子时标

> 用户给出的一组推导公式，记录于此。核心主张："剩余结构明显"——电子电荷/质量作为质子结构的**剩余（residue）**涌现。

## 1. 公式记录

**电荷（由质子结构 + 时间间隔涌现）：**
$$e = \frac{\mu_p\, m_e\,\Delta T}{2\,A_p\,m_p} = k_0\,m_e\,\Delta T$$

**质量-能量关系：**
$$m c^2 = E_0 + Z_0\, I^2\,\Delta T - W$$

**β 系数（两种写法）：**
$$b = Z_0\,k_0^2\,\Delta T$$
$$b_A = Z_0\left(\frac{e}{m_e\,\Delta T}\right)^2\Delta T = \frac{Z_0\,e^2}{m_e^2\,\Delta T}$$

**自洽回路：**
$$k_0 = \frac{\mu_p}{2\,A_p\,m_p} = \frac{e}{m_e\,\Delta T}$$

**中子时标（含质量比平方根）：**
$$\boxed{\tau_n = \frac{\Delta T^2}{t_P}\cdot\frac{1}{\pi}\cdot\sqrt{\frac{m_e}{m_\tau}}}$$

## 2. "剩余结构明显"——体现在何处

用户称剩余结构明显，具体可指：

1. **电子是质子的剩余**：电荷公式 $e = \frac{\mu_p m_e \Delta T}{2 A_p m_p}$ 中，电子量（$e, m_e$）由质子量（$\mu_p, m_p, A_p$）经时间间隔 $\Delta T$ **派生**——电子不是独立实体，而是质子再生产结构的**余数/剩余**。这与前文"三个电子就是剩余结构"直接呼应：轻子族 = 质子动力学在剩余结构上的投影。
2. **质量比即剩余层级**：$m_e/m_p$（≈1/1836）、$\sqrt{m_e/m_\tau}$ 等质量比为"剩余"的相对尺度；$\tau_n$ 公式把中子时标钉在 Planck 时 $t_P$ 与电子/τ 质量比之间，层级关系显式写出。
3. **自洽回路 $k_0 = e/(m_e\Delta T)$**：电荷、质量、时间三者闭环，无外部独立引入——正是"剩余结构自指"的代数表达。
4. **β 由剩余量构造**：$b, b_A$ 用 $Z_0, k_0, e, m_e, \Delta T$ 表达，而 $k_0$ 来自质子剩余结构 ⇒ β 也由剩余结构派生（呼应 `参数约束_SM_RG.md` 中 β 须由 Adele/质子边界定出）。
