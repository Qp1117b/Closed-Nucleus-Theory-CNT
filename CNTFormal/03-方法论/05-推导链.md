## 1. 推导总图

```
再生产动力学（μ∘μ=μ）→ p进数 → 壳层假设 → Poincaré半平面度规
  → Ĥ = D̂² + 1/4 → 谱 E_n = 1/4 + γ_n² → C = ξ'(1)/ξ(1)
  → 传输方程 ∂_τΨ + Ce^u∂_uΨ = 0 → RG等价 → 四维相空间
  → SU(5) Weyl 对称性 → W_m = 5·2^{m-1}
  → 规范耦合 β-函数 → 物理常数涌现
       │
       ├── 规范侧（语法层，自动）：群候选 → 破缺 → F² + Dμ
       └── 非规范侧（语义层，涌现）：质量谱 → 混合 → CP
```

**核心洞见**：仅一个公理（物质先在）+ 一个实验输入（m_p），通过再生产动力学→壳层几何→谱理论→群论→退相干的必然链条，涌现标准模型全部结构与常数。规范部分是语法层的数学必然，非规范部分（质量、混合、CP）必须从再生产动力学真实涌现。

### 第一阶段：本体结构（壳体理论）

| 项目 | 内容 |
|---|---|
| 研究问题 | 给定一个有限存在者，它如何持续维持自己的结构形式？ |
| 核心操作 | 从"物质先在"到"壳体发现"——离散再生产必然产生层级结构 |
| 输出 | μ∘μ=μ（L1）、ℤ_p = lim⟵ ℤ/p^nℤ（L2）、★壳层发现 |
| 覆盖步骤 | ③-⑦ |

**步骤分解**：

**③ 再生产 → μ∘μ=μ**：再生产态射是幂等的——每次再生产完成后闭合核回到形式结构同一性。再生产频率由几何结构内在决定：f_rep = c/ℓ₀，ℓ₀ ≈ 0.84 fm。

**④ 再生产离散 → p进数**：再生产是离散事件序列，自然指向逆极限结构 ℤ_p。不是"选择"了p进数，而是再生产逻辑在数学上唯一地指向p进数。双重角色：层析论（空间分析）= 投射极限；循环论（时间分析）= 赋值计数。

**⑤-⑦ 壳层→哈密顿量→谱→C**：从壳层假设经Poincaré半平面度规导出 Ĥ = D̂² + 1/4，谱 E_n = 1/4 + γ_n²，C = ξ'(1)/ξ(1)。（严格数学证明）

**覆盖文档**：`08-计算框架/01-数学化纲领 §1-3`

**决策记录**：
| 决策 | 理由 |
|---|---|
| 合成p进数 → 暂弃 | 加法未定义、无环结构、物理产出不足 |
| 标准adelic框架 → 保留 | 经典p进展开容纳费曼图不受影响 |

### 第二阶段：时空兼容（SR/GR）

| 项目 | 内容 |
|---|---|
| 研究问题 | 离散固有时如何与连续的经典时空相容？ |
| 核心操作 | 从壳体到4维相空间——离散再生产与连续时空相容 |

| 覆盖步骤 | ⑧-⑫ |

**SR/GR兼容机制**：
- 尺度收缩 → 曲率增大：K(v) ∝ γ²K₀
- 时间膨胀 = 再生产周期变化：T_rep(v) = γ·T_rep(0)
- 统一：T_rep(g_μν)/T_rep(η_μν) = √(-g₀₀)
- 光速涌现：c = √2·ℓ₀·f_rep（c不是基本常数，是几何与动力学的同构）

**RG等价性**（五环节独立论证）：(g₁, g₂, g₃; τ) ≅ (g₁, g₂, g₃; lnμ)

| 项目 | 内容 |

G_N = I · λ_c · C² · E₁ · exp(-2/C) / m_p²（偏差 −2.3%）


### 第七阶段：禁闭机制

| 项目 | 内容 |
|---|---|
| 研究问题 | 力-距离分层如何解释夸克禁闭？ |
| 核心操作 | 禁闭 = 壳层退相干 |
| 输出 | 色禁闭 = 壳层退相干、中子结构（提案） |
| 覆盖步骤 | — |

**核心等式**：夸克禁闭 ≡ 壳层退相干

**机制**：SU(3)的p=2结构使色荷自由度在有限因果域内自我截断——没有足够的因果分辨率分辨个别色荷的自由传播。色荷被困在壳层退相干区域内。

**中子结构（提案）**：中子 = 正四单纯型电荷破缺缺陷态（同一4-simplex的某一顶点发生 u↔d 局部翻转）。质量差 m_n − m_p = 1.293 MeV = 缺陷位的拓扑张力。β衰变 = 缺陷位通过再生产坍缩自发修复。详见 `08-计算框架/06-中子结构`。

**覆盖文档**：`08-计算框架/06-中子结构`、`01-公理体系/01-费曼图的本质`
