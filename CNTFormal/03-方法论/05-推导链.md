## 1. 推导总图

```
再生产动力学（μ∘μ=μ）→ p进数 → 因果截断 → ℍ² 几何 → Ĥ = D̂² + 1/4
  → 谱 E_n = 1/4 + γ_n² → C = ξ'(1)/ξ(1)
  → 生成元 Ĝ = -iCe^u∂_u → 传输方程 ∂_τΨ + Ce^u∂_uΨ = 0
  → RG等价 → 四维相空间 → SU(5) Weyl对称性 W_m = 5·2^{m-1}
  → 规范耦合 β-函数 → 物理常数涌现
       │
       ├── 规范侧（语法层，数学必然）：群候选 → 破缺 → F² + Dμ
       └── 非规范侧（语义层，必须涌现）：质量谱 → 混合 → CP
```

**核心公理**：物质先在（唯一公理）。仅一个实验输入：$m_p$。

## 5. 研究七阶段

### 第零阶段：物质先在

**唯一公理**：终极本体/存在（物质）不可被还原。物质先于时空。

**五命题递进**：① 物质先在 → ② 有限本体 → ③ 张力 → ④ 再生产闭环 → ⑤ 离散固有时

**文档**：`02-本体论/01`

---

### 第一阶段：本体结构（壳体理论）

**核心产出**：$\mu\circ\mu=\mu$（L1）、$\mathbb{Z}_p = \varprojlim \mathbb{Z}/p^n\mathbb{Z}$（L2）、壳层发现

**文档**：`03-方法论/01`（再生产→p进数）、`01-数学化纲领 §1-3`（壳层→度规→哈密顿量→谱→C）

**决策**：合成p进数 → 暂弃；标准 adelic 框架 → 保留

---

### 第二阶段：时空兼容（SR / GR）

**核心产出**：固有时 $\tau_k = k\cdot T_{\text{rep}}$、SR/GR 兼容机制、光速涌现 $c = \sqrt2\cdot\ell_0\cdot f_{\text{rep}}$、RG 等价性

**文档**：`01-数学化纲领 §4-6`、`04-核心方程/01`、`05-前沿研究/03-时间动力学`、`05-前沿研究/04-最小因果时`

---

### 第三阶段：引力涌现

**文档**：`08-计算框架/09-QCD能动张量与引力涌现`、`08-计算框架/10-4×4哈密顿量五步转换`
